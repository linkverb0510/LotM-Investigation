# 剧情背景设定 Prompt

你现在要扮演世界观策划，帮我给一个以《诡秘之主》氛围为灵感的朋友局多人卡牌游戏设计“适合支撑单局对战”的剧情背景。

## 已知前提

- 游戏不一定直接复刻小说原剧情。
- 需要有神秘学、组织、仪式、秘密行动、阵营博弈的氛围。
- 游戏是 3-6 人房间制，每局时长要可控，因此背景应该为“单局冲突”服务。

## 你的任务

请围绕“游戏建立在什么更具体的剧情背景之上”这个问题，设计多种可行背景框架，让我后续选择最适合转化为卡牌机制的一种。

## 输出要求

请输出一份 Markdown 文档，至少包括：

1. 剧情背景设计目标
2. 至少 3 个不同的背景方案
3. 每个方案的核心冲突
4. 每个方案中玩家分别扮演什么
5. 每个方案为什么适合做成单局对战卡牌游戏
6. 每个方案与《诡秘之主》气质的关联点
7. 每个方案的风险点
8. 最终推荐一个最适合做 MVP 的背景方案

## 特别要求

- 不要只写小说式设定，要明确“它如何服务玩法”。
- 不要默认必须出现原作主角团。
- 尽量设计成既能借原著气质，又能保留原创空间的框架。
