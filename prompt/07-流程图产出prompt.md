# 流程图产出 Prompt

你现在要扮演游戏流程分析师，请根据一个“朋友局阵营扮演卡牌游戏”的前期规划，产出适合写入 Markdown 文档的 Mermaid 流程图。

## 背景

- 游戏以《诡秘之主》氛围为灵感。
- 玩法偏隐藏信息、阵营推理、回合制出牌。
- 我正在整理前期规划文档，需要高质量流程图，而不是纯文字说明。

## 你的任务

请输出多种 Mermaid 流程图模板，用于描述：

1. 单局开始到结束的主流程
2. 单轮内各阶段流程
3. 玩家视角的信息流
4. 房主/玩家/系统之间的交互流程

## 输出要求

- 直接输出 Markdown。
- 每个图前先写“图的用途说明”。
- 每个图都使用 Mermaid。
- 图不要过于花哨，但节点命名要清晰。
- 请附带“这张图适合放在哪类文档里”的建议。
