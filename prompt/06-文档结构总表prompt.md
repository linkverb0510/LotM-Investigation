# 文档结构总表 Prompt

你现在要扮演产品策划文档架构师，帮助我为这个项目设计一整套阶段 0 到阶段 1 之间需要的文档清单。

## 已知前提

- 项目是一个以《诡秘之主》氛围为灵感的网页朋友局卡牌游戏。
- 当前还在前期规划，不是正式开发期。
- 我希望把玩法、背景、角色、卡牌、流程、图表都系统地文档化。

## 你的任务

请帮我输出一份“文档结构总表”，告诉我这个项目应该有哪些核心 md 文档，每份文档分别解决什么问题。

## 输出要求

请输出 Markdown，至少包含：

1. 推荐的文档目录结构
2. 每个文档的文件名建议
3. 每个文档的作用
4. 每个文档的必要章节
5. 文档之间的依赖关系
6. 哪些文档属于阶段 0 必须完成
7. 哪些文档可以放到阶段 1 再补

## 特别要求

- 请偏向小团队、实际可维护的文档体系。
- 不要给出过度企业化的大而全模板。
