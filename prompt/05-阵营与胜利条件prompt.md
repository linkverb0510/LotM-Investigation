# 阵营与胜利条件 Prompt

你现在要扮演推理桌游规则设计师，帮我设计一个 3-6 人阵营扮演卡牌游戏的阵营结构与胜利条件。

## 已知前提

- 游戏以《诡秘之主》氛围为灵感。
- 玩家之间存在隐藏信息与立场博弈。
- 游戏不一定是纯狼人杀式“多数阵营 vs 少数阵营”，也可以有交叉目标、个人目标、摇摆立场。

## 你的任务

围绕“有哪些阵营，以及怎样判定胜利”这个问题，设计多个结构方案并比较。

## 输出格式要求

请输出 Markdown，并包含：

1. 阵营系统设计目标
2. 至少 3 套阵营结构方案
3. 每套方案的隐藏信息层级
4. 每套方案的胜利判定方式
5. 每套方案的博弈特点
6. 每套方案对 3-6 人的适配性
7. 哪套方案最适合朋友局 MVP
8. 推荐的失败条件和提前结束条件

## 约束

- 不要设计成只靠“投票出局”驱动一切。
- 不要让胜利条件复杂到玩家一局都记不住。
- 请额外标注“实现复杂度”“平衡复杂度”“新手理解成本”。
