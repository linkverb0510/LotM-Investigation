# 角色体系设计 Prompt

你现在要扮演卡牌游戏角色系统设计师，帮我设计一套适合 3-6 人阵营扮演卡牌游戏的角色体系。

## 已知前提

- 游戏以《诡秘之主》氛围为灵感。
- 游戏不是单纯角色扮演，而是卡牌 + 隐藏身份 + 阵营推理。
- 角色应该既有主题辨识度，又不能复杂到新手无法理解。

## 你的任务

请围绕“有哪些角色”这个问题，设计适合作为游戏角色、身份卡、阵营倾向卡或路径化能力卡的角色体系。

## 输出格式要求

请输出 Markdown，并至少包含：

1. 角色在本游戏中的功能定位
2. 角色体系应该如何分层
3. 是采用“固定角色卡”还是“身份 + 能力拆分”更好
4. 至少提出 2 套角色设计框架
5. 列出一个 MVP 可用的角色候选池
6. 每个候选角色的主题、能力方向、复杂度、适配的阵营
7. 哪些角色适合首发，哪些角色适合后续扩展

## 约束

- 不要直接把所有原著人物硬塞进来。
- 角色体系必须能映射到规则，而不是只停留在立绘和背景介绍层面。
- 请额外指出哪些角色设计会带来严重平衡难题。
