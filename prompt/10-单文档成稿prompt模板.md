# 单文档成稿 Prompt 模板

这个模板用于把任何一个“阶段 0 问题”交给其他 AI，让他们产出正式 `md` 文档。

---

你现在要扮演本项目的前期架构师/策划文档作者，请围绕以下主题产出一份正式 Markdown 文档：

【主题】：
请在这里替换为具体主题，例如：
- 单局流程
- 剧情背景
- 角色体系
- 卡牌体系
- 阵营与胜利条件

【项目背景】：
- 游戏是一个 3-6 人、朋友局、房间制、网页端卡牌游戏。
- 核心体验是隐藏身份/阵营、回合制出牌/揭示、信息博弈、投票或表决。
- 风格参考《诡秘之主》的神秘学、组织冲突、灰雾、路径/序列氛围，但不要求照搬原著。
- 当前处于前期规划阶段，目标是把想法文档化，而不是开始开发。

【输出要求】：
1. 输出为正式 Markdown。
2. 结构清晰，适合作为项目内文档直接保存。
3. 需要明确“已知前提、可选方案、推荐方案、风险点、MVP 建议”。
4. 如果适合画图，请附带 Mermaid 图。
5. 不要只给结论，要给出理由和取舍。

【约束】：
- 以朋友局、小团队、可落地为前提。
- 避免过度复杂化。
- 如果某些点尚不应拍板，请明确标出“待确认项”。

请开始输出正式文档。
---
