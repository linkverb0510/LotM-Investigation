# 道具与卡牌体系 Prompt

你现在要扮演卡牌系统策划，帮我设计一个以《诡秘之主》氛围为灵感的多人阵营扮演卡牌游戏的道具与卡牌体系。

## 已知前提

- 玩家会通过卡牌驱动行动与信息博弈。
- 游戏强调隐藏信息、明牌/暗牌、投票和回合推进。
- 道具、仪式、封印物、情报、身份线索等都可以抽象为卡牌。

## 你的任务

请围绕“有哪些道具以及卡牌类型”这个问题，设计一个适合 MVP 的卡牌体系框架，而不是单纯堆卡名。

## 输出要求

请输出 Markdown，至少包含：

1. 卡牌系统在整局中的作用
2. 卡牌应该分成哪些大类
3. 每类卡牌承载什么功能
4. 道具/封印物/仪式/情报类设计如何区分
5. 每类卡牌各给出一些示例
6. 哪些卡牌适合明置，哪些适合暗置
7. 哪些卡牌更适合作为事件牌而不是手牌
8. 给出一版 MVP 卡池建议

## 额外要求

- 不要只做“原著名词皮肤化”，要说明机制价值。
- 请指出哪些卡牌类型会提升互动，哪些会拖慢节奏。
- 请给出“适合网页实现”的建议。
