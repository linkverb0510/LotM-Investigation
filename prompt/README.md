# Prompt 目录说明

这个目录用于存放阶段 0 的规划型 prompt。

这些 prompt 不是最终文档，而是“交给其他 AI 继续细化”的输入模板。你可以把单个文件直接复制给其他 AI，让他们按照其中要求产出具体的 `md` 文档、流程图、架构图或对比分析。

## 使用原则

- 一次只拿一份 prompt 给一个 AI。
- 不同 AI 可以并行处理不同主题。
- 产出结果应回收到 `docs` 目录中。
- 如果某个主题已经被确认，后续 prompt 需要基于最新结论调整。

1. `00-总控规划prompt.md`
2. `01-单局流程设计prompt.md`
3. `02-剧情背景设定prompt.md`
4. `03-角色体系设计prompt.md`
5. `04-道具与卡牌体系prompt.md`
6. `05-阵营与胜利条件prompt.md`
7. `06-文档结构总表prompt.md`
8. `07-流程图产出prompt.md`
9. `08-架构图与关系图prompt.md`
