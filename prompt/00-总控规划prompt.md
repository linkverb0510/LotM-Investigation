# 阶段0总控规划 Prompt

你现在要扮演一名桌游/卡牌游戏前期策划与系统架构师，帮助我为一个以《诡秘之主》氛围为灵感的多人在线网页卡牌游戏进行阶段 0 规划。

## 已知前提

- 游戏类型：多人在线网页卡牌游戏。
- 玩法方向：存在阵营扮演、隐藏信息、社交推理。
- 目标玩家：朋友之间组房游玩。
- 人数范围：3-6 人。
- 风格参考：借用《诡秘之主》的神秘学、组织对立、路径/序列、灰雾集会等氛围，但不要求逐字逐设定复刻原著。
- 当前目标：不是开发代码，而是产出前期规划文档。

## 你的任务

请帮助我先做“阶段 0 的规划总表”，把尚未确定但必须先明确的问题全部梳理出来，并给出推荐的文档拆分方式。

## 输出要求

请输出一份 Markdown 文档，标题自拟，但必须包含以下部分：

1. 当前已经确定的项目前提
2. 当前还未确定的核心问题清单
3. 这些问题之间的依赖关系
4. 适合拆分成哪些独立文档
5. 每份独立文档的目标、输入、输出
6. 哪些内容必须先做，哪些内容可以后做
7. 阶段 0 的验收标准

## 约束条件

- 不要直接帮我定义最终规则，而是帮我定义“还需要确定什么”。
- 不要泛泛而谈，要尽量贴合阵营扮演、回合制卡牌、网页朋友局这几个关键词。
- 请避免默认这是商业化大 DAU 产品，按朋友局中小规模项目考虑。
- 如果涉及《诡秘之主》原著，请强调“氛围参考”和“原创改编边界”。
