# 本轮开发计划

## 1. 本轮目标

在调查模式文档体系与角色体系已完成的基础上，本轮推进两个方向：

1. **跑团核心机制落地**：将「不同序列·不同能力」从文字背景变为可操作的数值差异——引入 D20 属性检定体系
2. **调查循环闭环**：让角色分配 → 行动检定 → 线索获取 → 讨论拼合 → 收束路由形成完整可玩闭环

## 2. 本轮范围

- 实现六属性体系（灵性/洞察/意志/体质/诡诈/知识）+ 12 个角色专长
- 实现 D20 骰子引擎（五档结果 + 难度修正 + 专长触发）
- 扩展 Storylet 加入检定配置（check + results 字段）
- 实现行动-检定映射与结算逻辑
- 实现合作检定机制（同地点互补 + 加值合作）
- 游戏设计参考沉淀（博德之门3、极乐迪斯科）

不做的内容：
- 不对决模式做任何推进
- 不新增角色或案件
- 前端 UI 重构延后至 M4（当前先确保后端逻辑完整）

## 3. 任务拆分

1. ✅ 属性系统数据层：六属性定义 + 角色属性表 + 专长表（`attributes.ts`）
2. ✅ 骰子引擎：D20 随机 + 五档判定 + 难度修正 + 专长触发（`dice.ts`）
3. ✅ Storylet 检定扩展：5 条关键 Storylet 加入 check/results 字段
4. 🔲 行动-检定映射：将七类行动动词接入 dice 引擎
5. 🔲 合作检定：同地点互补检测 + 加值合作 + 合成洞察
6. 🔲 Docs 架构整理：归档旧文件 + 分类重组 + 内容修订

## 4. 本轮产出

1. ✅ `docs/开发相关文档/玩法机制/RPG核心机制设计文档_20260518.md`
2. ✅ `src/lib/game/investigation-v2/attributes.ts`
3. ✅ `src/lib/game/investigation-v2/dice.ts`
4. ✅ `src/lib/game/investigation-v2/schema.ts`（扩展 8 个新类型）
5. ✅ `src/lib/game/investigation-v2/storylets.ts`（5 条改写）
6. 🔲 游戏设计参考文档（博德之门3 / 极乐迪斯科分析）
7. 🔲 Docs 架构重组（分类目录 + 修订旧文档）

## 5. 验收标准

- 6 个角色各自拥有不同的六维属性分布和 2 个专长
- 调查行动触发 D20 检定，产生 5 档不同的叙事结果
- 每档结果（天启/成功/勉强/失败/灾厄）都有不同的线索产出和代价
- 骰子难度受环境修正（压力等级/地点/物品持有/合作）动态影响
- Docs 目录结构清晰分层，旧文档已归档，入口文档已更新
