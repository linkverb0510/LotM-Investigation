# 角色卡：代罚者军官

> **本名 / 常用名**：奥斯顿·雷文斯
> **角色头衔**：雷律执行官
> **所属组织**：风暴之主教会 · 代罚者
> **途径**：水手途径
> **序列**：序列7 航海家
> **公开职责**：封锁现场、护送目标、强制中断危险行为
> **调查定位**：强制介入 / 风险控制 / 高压执行
> **上手难度**：3 / 5

## 1. 固定角色核心档案

### 本案出场理由

东区异常死亡案在教会内部被判断为“可能出现扩散性风险”后，单靠值夜者已经不足以压住所有现场变量。  
奥斯顿因此被作为风暴教会的执行支援派来。他的任务不是优先写报告，也不是温和沟通，而是确保：

- 不该失控的人不继续失控
- 不该离开现场的物品不被带走
- 不该单独行动的人被及时截住

### 基础性格与公众印象

他给人的第一印象往往是粗暴、直接、不喜欢绕弯。  
但那种粗暴并不是情绪化，而是一种很明确的执行观：当危险已经在眼前时，先把人、门、物件和命令都按住，再谈更精细的判断。

### 在队伍里的自然位置

如果说梦魇负责稳住“心”和“局面”，那航海家负责稳住“边界”和“动作”：

- 谁不能继续碰那件东西
- 谁现在不适合被放着单独行动
- 哪扇门必须现在就封
- 哪个决定再拖一轮就会出事

## 2. 建议初始属性

- 最大灵性：5
- 起始污染：1
- 起始线索：0
- 起始手牌：3

## 3. 调查模式规则层

### 角色天赋：风暴审视

当本局已进入高压状态时，你的 `压制` 或 `封锁` 类行动会获得额外效果，例如延长限制时间，或在控制住局面后额外获得一次轻度搜证机会。  
如果本轮有人明显违反了讨论达成的集体措施，你还可以在行动结算后获得一次补充说明权。

### 专属卡牌 1：现场勘查

- 类型：搜证
- 消耗：1 灵性
- 效果：利用航海家对环境细节和危险征兆的敏感，快速扫过现场。获得 1 条线索；若本轮已经有人触发公共异常，则再额外确认这条异常更偏向 `人为 / 仪式 / 物件`。

### 专属卡牌 2：雷霆震慑

- 类型：压制
- 消耗：2 灵性
- 效果：你强行中断一名目标对 `地点 / 物件 / 私密接触` 的持续操作，并令其在下轮讨论中更难回避说明。  
若该目标本轮已被多数人重点关注，则你还会额外获得一条关于他当前动作的半公开痕迹。

### 专属卡牌 3：风暴教会徽记

- 类型：调度
- 消耗：1 灵性
- 效果：调用风暴教会执行权限。你可以立刻推动一次轻度封锁、陪同调查或物件交接，不必等待下一轮讨论结论。  
代价是你的组织立场会更明显，后续更容易触发“越权处置”相关争议。

### 讨论杠杆

代罚者军官在讨论中最重要的价值不是“判断真相”，而是把桌上的结论转换成现实后果：

- 谁如果再单独行动会出事
- 哪条措施如果不立即执行，下一轮就来不及
- 哪类宽容其实是在给污染留活路

## 4. 私人牵挂与代价

### 私人牵挂

奥斯顿最在乎的是“不要再让组织之间的犹豫把局面拖坏”。  
他曾见过足够多“大家都觉得再观察一轮更稳妥”的场合，最后只换来更多尸体和更大的代价。

### 风险 / 代价

- 他过于相信先封锁后解释的处理顺序
- 他很容易把不配合解释为有问题
- 一旦他判断错了，造成的伤害往往比别人更直接

### 哪些话题会击穿他

- 被指责为“你只是想靠权力压过去”
- 被拿过去的执行失误反问
- 看到自己刚放行的人立刻造成更大异常

## 5. Storylet 钩子

- 开场私密：你接到的补充命令里有一句与公开指令不同的话：“若事态超出控制，优先保住封印物，不计代价。”
- 中盘反应：若你两次以上推动高压措施，系统会额外给予你一条“局势确实在恶化”的提示，但也会放大他人对你越权的警惕。
- 讨论关系：当值夜者主张再观察一轮，而你判断必须立刻封锁时，会触发组织摩擦关系事件。
- 结局余波：如果你的强制措施救下了局面，你会被记录为“果断”；如果判断错误，同样的行为会被写成“粗暴失当”。

## 6. 背景剧情

奥斯顿并不是那种典型会被人喜欢的执行者。年轻时的他在港口、风暴线、海上护送与沿岸清剿里待得太久，早就习惯用最短的时间判断一件事值不值得立刻按住。他见过超凡事件最糟糕的模样：并不是怪物突然张开爪牙，而是人们在还拿不准的时候，给了它第二次呼吸的机会。

水手途径让他对环境变化、危险征兆和行动时机异常敏锐。很多人觉得他的能力更适合战斗，但真正见过他处理现场的人会明白，他的价值不是单纯“能打”，而是能在最短时间里看出“哪一步如果不立刻做，接下来会崩”。也正因为如此，他和很多更重视程序与细节判断的人经常产生冲突。对他来说，讨论是必须的，但讨论不能代替执行。

东区这起案子一开始就让他觉得不舒服。不是因为案情多离奇，而是因为太多细节看起来都像在拖时间：封存命令来得太慢，记录缺页缺得太巧，现场有人主张先安抚、再观察、最后再决定处置。奥斯顿很熟悉这种节奏，因为它通常意味着某些人还没意识到，危险已经不再等他们把流程走完。

他不介意被人当成粗暴的那一个。只要最后证明那些门确实该锁、那些人确实不该单独行动、那些物件确实差一点就被带出现场，他宁可在会议里做最不讨喜的声音。

## 7. 风味台词

“等你们把话都说圆了，门后的东西往往也已经把它该做的做完了。”
