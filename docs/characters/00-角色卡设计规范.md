# 角色卡设计规范

本文档用于约束 `docs/characters/` 目录下的固定角色写法。  
当前项目已经从“公开敌对角色 + 混合原型”转向：

- `固定公开角色池`
- `可变隐情包`
- `关系包`
- `Storylet 钩子`

所以角色文档不再只是一张“有技能的身份卡”，而要成为后续剧情、行动卡、讨论机制和结局余波的共同上游。

## 一、角色设计的核心原则

### 1. 角色先是“人”，再是“能力包”

玩家真正能记住的，从来不是“这张卡能做什么”，而是“这个人为什么这么做”。  
所以每个固定角色都必须先回答：

- 他是谁
- 他来自哪里
- 他为什么会被卷入这起案子
- 他最在乎什么
- 他最怕什么被揭开

能力文本只是这些人物事实在规则层的投影。

### 2. 固定角色和敌对身份必须拆层

调查模式要让所有固定角色都能自然进入调查现场。  
这意味着：

- 固定角色卡只写“公开可入队角色”
- `极光会渗透者`、`失控边缘`、`旧案压案者` 这类内容不再直接写成公开角色
- 这些危险内容转入 `可变隐情包`、`状态包`、`关系包`

这样做的原因不是删设定，而是让角色池能长期扩展，同时保持世界观合理性。

### 3. 角色的讨论价值要和背景绑定

如果一个角色在讨论中只能说“我觉得他可疑”，那这个角色仍然是空的。  
每个固定角色都必须拥有独特的话语来源，例如：

- 梦魇：旧案经验、现场秩序、梦境审问
- 通灵者：尸体、残响、死者最后的信息
- 魔术师：隐秘接触、真假痕迹、被遮掩的中间环节
- 代罚者：封锁、护送、越权处置的现实后果
- 心理医生：情绪失真、承诺破绽、集体恐慌
- 巫师：仪式学、物件风险、知识代价

### 4. 术语必须稳定

同一个概念在不同角色卡里不能反复换名字。  
固定角色卡统一使用以下核心术语：

- 灵性
- 污染
- 线索
- 封印物
- 调查动作
- 讨论杠杆
- 私密隐情
- 关系包
- Storylet 钩子

## 二、固定角色的四层模型

从这一轮开始，每个固定角色都按四层来写。

### A. 固定角色核心档案

这是公开层，描述“所有人都能理解为什么他会出现在现场”：

- 本名 / 常用名
- 角色名
- 角色头衔
- 所属组织
- 途径 / 序列
- 公开职责
- 本案出场理由
- 基础性格与公众印象

### B. 规则层角色卡

这是玩法层，描述“他怎样介入案件”：

- 建议初始属性
- 调查模式定位
- 角色天赋
- 3 张专属行动卡
- 讨论杠杆
- 扮演要点
- 代价与弱点

### C. 私密层

这是代入层，描述“他不想让别人知道什么”：

- 私人牵挂
- 可挂载的隐情方向
- 哪类信息最容易击穿他

### D. Storylet 钩子层

这是叙事层，描述“系统应该怎样让这个角色活起来”：

- 1 个开场私密钩子
- 1 个中盘行为反应钩子
- 1 个讨论阶段关系钩子
- 1 个结局余波钩子

## 三、固定角色文档统一模板

每个固定角色文件统一包含以下部分：

1. `角色概览`
- 角色名
- 本名 / 常用名
- 角色头衔
- 所属组织
- 途径 / 序列
- 公开职责
- 调查定位
- 上手难度

2. `固定角色核心档案`
- 本案出场理由
- 基础性格与公众印象
- 他在队伍里最自然扮演什么位置

3. `建议初始属性`
- 最大灵性
- 起始污染
- 起始线索
- 起始手牌

4. `调查模式规则层`
- 角色天赋
- 3 张专属行动卡
- 讨论杠杆

5. `私人牵挂与代价`
- 私密牵挂
- 风险 / 代价
- 哪些话题会让他失衡

6. `Storylet 钩子`
- 开场私密
- 中盘反应
- 关系触发
- 结局余波

7. `背景剧情`
- 至少一段完整、具体、可代入的背景说明

8. `风味台词`
- 为 UI、角色揭示、结局余波准备文案素材

## 四、写作边界

- 不在固定角色卡里写“这个人其实一定是坏人”。
- 不在固定角色卡里写“审查结论”“优化说明”“设计争议”。
- 不把敌对身份直接写死在公开角色里。
- 不把组织身份和途径混写，例如：
  - `值夜者` 是组织职位，不是途径
  - `代罚者` 是教会执行体系，不是途径
- 固定角色卡优先服务于：
  - 代入感
  - 可玩性
  - 世界观一致性
  - 后续文档复用

## 五、与隐情包、关系包的关系

固定角色文档本身不负责穷尽所有变化。  
变化内容统一放到独立文档：

- `固定角色模板文档`
- `可变隐情包与关系包文档`

也就是说：

- 角色卡负责“这个人平时是谁”
- 隐情包负责“他这局正在隐瞒什么”
- 关系包负责“他和谁之间有什么没说完的历史”
