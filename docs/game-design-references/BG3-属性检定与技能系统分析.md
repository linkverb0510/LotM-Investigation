# 博德之门3 — 属性检定与技能系统分析

## 基本信息
- 游戏名称：博德之门3（Baldur's Gate 3）
- 游戏类型：CRPG / 跑团电子化
- 记录日期：2026-05-18
- 参考资料：D&D 5E SRD / BG3 游戏内系统

## 核心机制摘要
- 机制名称：D20 属性检定 + 技能熟练项 + 优势/劣势
- 规则入口：任何有不确定性结果的行动（对话说服、察觉陷阱、撬锁、战斗命中）
- 玩家决策点：
  1. 选择「用哪个属性/技能」来应对挑战（如：威胁用力量、说服用魅力）
  2. 消耗资源（法术位、激励点）来获取优势（掷两次取高）
  3. 根据角色 build 决定「擅长什么、回避什么」
- 风险与回报：
  - 成功：推进剧情 / 避免战斗 / 获得隐藏信息
  - 失败：触发替代剧情（失败也是故事的一部分，而非死胡同）

## 为什么这个机制有效

BG3 的检定系统之所以令人上瘾，是因为**每一次掷骰都意味着玩家在做选择——而这个选择反映的是「你的角色是谁」而非「你作为玩家的操作水平」**。魅力 18 的吟游诗人可以用对话绕过一场 Boss 战，力量 20 的野蛮人可以砸开锁住的门——两者都能达成目标，但以完全不同的方式。

第二个关键是**失败也有趣**。BG3 中大多数关键检定失败并不会导致 Game Over，而是触发一条替代剧情线。这意味着大失败不是惩罚，而是另一种展开。这消除了玩家对随机性的恐惧——掷骰变成了一种期待而非焦虑。

第三个关键是**属性让角色扮演有了牙齿**。智力 8 的野蛮人在对话中说出蠢话是合理的——因为玩家选择玩智力 8 的时候就已经接受了这个后果。这让「角色 build」不再只是战斗数据，而是叙事身份的一部分。

## 对本项目的启发

### 可以直接借鉴的
1. **六属性区分行动**：我们的灵性/洞察/意志/体质/诡诈/知识体系与 D&D 六属性高度对应。可以效仿 BG3 的做法——让每个属性在不同调查场景中都有独特的应用途径（如洞察用于识破谎言、诡诈用于伪造痕迹）
2. **失败叙事化**：我们的「灾厄」档位设计已吸收了这个理念——灾厄不是空手而归，而是获得被污染扭曲的误导信息
3. **属性决定角色身份**：艾德温灵性6意志5 vs 奥斯顿体质6诡诈1——就像 BG3 中不同职业的属性分布差异

### MVP vs 后续版本
- MVP 适用：基础属性检定（D20 + 属性 vs 难度）
- 后续可加：优势/劣势机制（如持有特定物品或专长时掷两次取高/低）

### 借鉴的是「规则」还是「体验目标」
借鉴的是「体验目标」——即「让属性差异成为玩家能感受到的角色身份差异」，而非照搬 D&D 规则的具体数值。

## 不应直接照搬的部分
- D&D 的技能熟练项过于细碎（20+ 个技能），我们的 6 角色 × 6 属性已足够区分
- BG3 的法术位/短休/长休资源系统不适合 60 分钟的单局游戏
- 优势/劣势机制会显著增加复杂度，适合作为 M3+ 的增强功能
