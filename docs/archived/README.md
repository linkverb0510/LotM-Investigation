# Archived 文档说明

本目录用于保存**已失去当前规范效力**、但仍有历史参考价值的文档与素材。

## 1. 什么文档会进入这里

- 重复版本
- 已完成的阶段性计划
- 早期草案
- 临时测试问题清单
- 单次开发过程报告
- 调试副产物

## 2. 进入归档不代表“没价值”

进入归档的原因通常不是内容差，而是它已经不适合继续扮演“当前版本”的角色。

一个简单类比：

- 活文档像“最新版操作手册”
- 归档文档像“旧版方案和会议纪要”

两者都能保留，但不能混着用。

## 3. 使用规则

1. 归档文档默认不作为当前实现依据。
2. 如果需要恢复某份归档文档为主版本，应先明确原因，再移动回活文档目录。
3. 新的历史资料也优先归入这里，而不是继续堆在活目录下。
