# 设定修正清单（东区案件 Lore 校正版）

## 1. 文档用途

本清单用于统一《全案真相基准文档》修订版、《角色卡文档_v2》修订版，以及项目内后续相关文档的设定口径。

目标不是扩写新剧情，而是把已经具备张力的剧情骨架校正到更符合《诡秘之主》原著设定的版本上。

---

## 2. 组织与幕后链条修正

### 2.1 删除的错误设定

以下设定不再使用：

- 赫密斯教团
- Hermes Society
- 将“赫密斯语”误写成某个真实存在的组织来源

### 2.2 新的幕后链条

东区案件的来源拆为两层：

- 远因：`摩斯苦修会`及其外围知识网络保存、流出或间接传播了与第四纪赫密斯语仪式遗物相关的残卷、研究摘录与注释体系。
- 近因：`极光会 / 真实造物主污染链`影响了亚瑟的最终行动方向，使他从危险研究跨越到主动推动灾难。

### 2.3 设计理由

这样处理有三个好处：

1. `摩斯苦修会`与窥秘人途径、隐者途径、神秘学研究天然兼容，能承担“知识来源”这一层。
2. `极光会`与真实造物主的耳语、授意、疯狂污染天然兼容，能承担“灾难引爆”这一层。
3. 能同时保留你当前文档里的“学术式危险知识”与“宗教式末日压迫”两种张力，而不需要虚构原著中并不存在的组织。

---

## 3. 核心异常物修正

### 3.1 删除的旧名称

以下名称不再使用：

- 赫密斯共鸣碑
- 将异常物描述为类似程序装置、精神模板投射器的抽象设定

### 3.2 新名称与性质

建议统一使用：

- `赫密斯祷文石碑`
- 备用文案名：`错译祷碑`

它的本质不是“共鸣机器”，而是：

- 一件第四纪遗留的赫密斯语仪式遗物
- 一组被刻入石碑的祷文结构、导向逻辑与错误知识诱发机制
- 一件会让“不完整解读者”被错误知识逐步同化的危险封印物

### 3.3 封印物等级

统一改为：

- `至少 2 级封印物`
- 若完整激活并形成大范围灵性同调，其危险后果接近 `1 级边缘事件`

### 3.4 功能口径

统一改为“知识误读型 / 仪式闭环型”异常，而不是“精神模板程序型”异常。

它引发的现象包括：

- 共同噩梦
- 证词趋同
- 情绪基线缓慢同化
- 对补全或继续吟诵剩余祷文的冲动
- 对某些被改写祷文和错误解释产生“理所当然”的理解倾向

### 3.5 与途径的绑定关系

- `主绑定`：隐者途径（窥秘人、巫师）
- `利用者`：错误途径（解密学者）

解释：

- 隐者途径角色更容易看懂、误读、深读它的神秘学结构。
- 错误途径角色更擅长从破碎文本、残卷、缺页、错误记录中重构出可被利用的“近似真相”。

---

## 4. 途径与序列名称修正

### 4.1 必须钉死的 canon

- 隐者途径 `序列9`：`窥秘人`
- 隐者途径 `序列7`：`巫师`
- 错误途径 `序列7`：`解密学者`

### 4.2 必须删除的错误称呼

- 窥秘人途径序列9“阅读者”
- 窥秘人途径序列8/9“解密师”
- 把“解密学者”归给窥秘人途径

### 4.3 当前案件中的知识系分工

- `格里芬`：低序列 `窥秘人`
  - 功能：最早发现、最早误触、最早失控死亡的入口人物
- `伊莱亚斯`：`巫师`
  - 功能：现场真正能看懂仪式结构的人
- `亚瑟`：`解密学者`
  - 功能：残卷重组、文本拼接、真相误导、幕后操盘

### 4.4 设计理由

如果三人都维持为窥秘人途径，就会出现功能和气质高度重复的问题。现在改成“窥秘人 / 巫师 / 解密学者”三段式后：

- 格里芬负责“发现问题”
- 伊莱亚斯负责“理解问题”
- 亚瑟负责“利用问题”

这会让案件链条更清楚，也更符合推理叙事里的角色分工。

---

## 5. 亚瑟·霍尔文设定修正

### 5.1 删除的旧动机

不再使用：

- “为了晋升而设计一场大型活体实验”作为唯一核心动机

这个动机的问题是：

- 太像普通反派野心，份量不够
- 和《诡秘之主》里“高位知识 / 污染 / 授意”那种危险感不匹配

### 5.2 新动机口径

亚瑟的设定统一改为：

- 他最初接触第四纪遗物与残卷，确实有求知与晋升动机。
- 但后来真正推动他跨过界限的，不再是单纯野心，而是早年接触污染文献或异常祷文后留下的“被授意”后遗症。
- 他逐渐坚信自己并不是在制造灾难，而是在完成某种“必须被继续、必须被完成的启示”。

### 5.3 新的气质目标

亚瑟不再只是阴谋家，而是：

- 一名高智商、部分清醒、部分被牵引的执行者
- 他仍会掩盖、布局、误导，但其内在逻辑带有近乎宗教式的确信
- 他对石碑和残卷的关系，不是“我拿它做实验”，而是“它在一步步教我该怎么继续”

## 6. 术语统一替换表

| 旧写法 | 新写法 |
|---|---|
| Hermes Society / 赫密斯教团 | 删除，不再使用 |
| 赫密斯共鸣碑 | 赫密斯祷文石碑 / 错译祷碑 |

| ritual nodes | 仪式节点 / 灵性导引节点 |
| 阅读者（指隐者途径序列9） | 窥秘人 |
| 解密师（指窥秘人途径） | 删除，不再使用 |

## 7. 对项目内现有活文档的同步要求

后续若同步项目内文档，应优先检查以下口径：

- 不再把窥秘人途径角色写成“知识教会巫师”式的稳固归属，而应优先靠近 `摩斯苦修会 / 外围研究链 / 独立研究协助者` 的表达。
- 核心案件中若要固定东区第一案真相，应以“摩斯远因 + 极光近因”作为主版本。
- 所有与旧案、残卷、共同噩梦、证词异常有关的解释，都应建立在“错误知识 + 被污染的仪式闭环”之上，而不是抽象化的精神程序。

---

## 8. 使用方式

在后续扩写或修订文档时，可以把这个清单当作“设定 lint 规则”：

- 看见不存在的组织名，先改掉。
- 看见错误途径或错误序列名，先改掉。
- 看见抽象到脱离原著语感的异常物逻辑，先改回“封印物 + 祷文 + 仪式 + 污染”这一套语言。
- 看见角色动机只有“想晋升”，就继续补足污染、授意、旧案、组织和私人牵挂层。
