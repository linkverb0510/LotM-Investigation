# UI 重构升级计划：适配模型 A (Model A UI Overhaul)

> **For Hermes:** 本文档为 UI 重构提供设计指导，暂不执行。等待 Codex 或 Hermes 前端任务调度。

## 1. 设计目标
从“简单的卡牌对战 UI"升级为"**沉浸式搜证与生存 UI**"，重点突出 Boss 威胁、环境压力和隐藏身份氛围。

## 2. 核心界面模块重构

### 2.1 游戏大厅与开局 (Lobby & Intro)
*   **新增：阵营迷雾遮罩**
    *   开局不显示具体阵营图标。所有玩家统一显示为“调查组成员”。
    *   仅渗透者自己能看到隐藏的“极光会”徽记。
*   **新增：剧情开场演出 (P1)**
    *   全屏背景：停尸房阴暗冷色调。
    *   文字滚动：展示 P1 剧情文本（“尸体比活人更诚实……”）。

### 2.2 游戏主界面 (In-Game HUD)
*   **顶部栏 (Top Bar)**
    *   **Boss 威胁条 (Threat Bar)**：
        *   新增进度条，显示 `Boss.threatLevel` (0-100%)。
        *   颜色动态变化：绿 -> 黄 -> 红 (80% 时闪烁)。
        *   显示 Boss 名称：“失控的通灵者” (序列 7)。
    *   **阶段指示器 (Phase Indicator)**：
        *   显示当前轮次与阶段 (如：P2 / 阴谋暗流)。

*   **玩家手牌区 (Player Hand)**
    *   **卡牌分类筛选**：增加 Tab 切换 (Info / Utility / Ritual)，方便在 P1-P5 快速找到需要的能力。
    *   **动态置灰逻辑**：
        *   若处于 P1-P2 阶段，Ritual 类卡牌置灰（Tooltip: "当前阶段无法使用仪式力量"）。
        *   若污染 > 50%，高消耗卡牌置灰（Tooltip: "灵性狂乱，消耗翻倍"）。

*   **公共信息区 (Public Info)**
    *   **线索库 (Clue Pool)**：
        *   显示当前公共线索总数（用于解锁高级情报）。
        *   显示个人线索图标。
    *   **环境状态 (Environment Status)**：
        *   显示当前环境 Debuff (如：大雾霾 Lv.1)。

### 2.3 结算与演化界面 (Evolution & Result)
*   **中立演化弹窗 (P4 Trigger)**
    *   当 P4 结束时，触发全屏模态框。
    *   展示行为总结：“你进行了 3 次净化，2 次调查。人性战胜了疯狂。”
    *   视觉变化：背景从模糊变清晰（守序）或从清晰变血红（邪恶）。

## 3. 视觉风格指南 (Style Guide)
*   **色调**：
    *   守序：冷蓝/银色 (值夜者、风暴)。
    *   邪恶：暗红/黑金 (极光会、真实造物主)。
    *   环境：灰暗/雾霾色 (贝克兰德大雾霾)。
*   **卡牌样式**：
    *   **调查牌**：羊皮纸纹理，墨水字迹。
    *   **功能牌**：金属质感，教会徽记。
    *   **仪式牌**：破损边缘，血肉/低语纹理（仅对持有者可见）。

## 4. 开发优先级
1.  **P0**: 顶部栏重构 (Boss 威胁条 + 阶段指示)。
2.  **P1**: 卡牌动态置灰逻辑 + 分类筛选。
3.  **P2**: 线索库 UI 展示。
4.  **P3**: 剧情开场演出与中立演化弹窗。
