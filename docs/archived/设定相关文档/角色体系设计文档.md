# 角色体系设计文档 — 「值夜者档案：贝克兰德大雾霾」

> 本文档定义游戏的角色体系，包括角色分层、能力框架、MVP 角色候选池。角色=身份标签+途径能力模块，高差异化设计，角色即阵营。

---

## 1. 角色的功能定位

| 维度 | 说明 |
|------|------|
| 身份载体 | 角色是玩家的游戏身份，包含背景叙事、视觉标识、能力体系 |
| 阵营锚点 | 角色与阵营绑定，选择角色即确定阵营（但隐藏） |
| 能力来源 | 角色通过途径模块提供技能树和专属卡牌 |
| 叙事入口 | 角色是玩家代入剧情的入口，与 D2 背景设定联动 |

---

## 2. 角色体系分层

```
角色体系
├── 身份层（角色标签）
│   ├── 老值夜者
│   ├── 代罚者军官
│   ├── 塔罗会成员
│   ├── 极光会渗透者
│   ├── 流浪学者
│   └── 失控边缘者
│
├── 途径层（能力模块）
│   ├── 不眠者途径
│   ├── 水手途径
│   ├── 占卜家途径
│   ├── 窥秘人途径
│   └── 收尸人途径
│
├── 序列层（能力等级）
│   ├── 序列 9（基础能力）
│   ├── 序列 8（晋升后）
│   └── 序列 7（终极能力）
│
└── 卡牌层（技能实现）
    ├── 专属卡牌（角色特有）
    ├── 途径卡牌（同途径共享）
    └── 通用卡牌（所有角色可用）
```

---

## 3. 设计框架：身份 + 能力拆分

采用 **"身份标签 + 途径能力模块"** 的拆分设计：

| 层级 | 定义 | 示例 |
|------|------|------|
| 身份标签 | 角色的叙事身份和阵营归属 | "老值夜者·邓恩风格" |
| 途径模块 | 附加的能力体系，决定技能树和卡牌池 | "不眠者途径" |
| 卡牌结构 | 专属卡牌 (3-5) + 途径共享池 + 通用池 | 角色特色与策略深度的平衡 |
| 序列等级 | 游戏中的能力等级，可晋升 | "序列 9→序列 8" |
| 视觉标识 | 颜色标识 + 途径图标（MVP 阶段不制作立绘） | 调查者蓝/污染源红 |

**优势**：
- 身份标签提供叙事代入感和阵营绑定
- 途径模块提供能力差异化
- 序列等级提供局内成长空间
- 拆分设计便于后续扩展（新身份+新途径组合）

## 5. 各角色详细设计

### 5.1 老值夜者（调查者）

| 维度 | 内容 |
|------|------|
| 背景 | 永恒黑夜教会贝克兰德分部资深成员，参与过多次非凡事件处理 |
| 途径 | 不眠者 |
| 初始序列 | 序列 8 不眠者 |
| 晋升路线 | 序列 8 → 序列 7 梦魇 |
| 晋升条件 | 收集 2 份"安眠草药"+ 成功执行 2 次"守护"行动 + 扮演法加分（保护队友） |
| 专属卡牌 | "夜间视野"（查看 1 名玩家的污染度）、"守夜人警戒"（免疫 1 次污染检定）、"安魂曲"（净化 1 名玩家的污染） |
| 被动技能 | "经验老到"：调查阶段额外抽 1 张牌 |
| 复杂度 | 低（技能直观，适合新手） |

### 5.2 代罚者军官（调查者）

| 维度 | 内容 |
|------|------|
| 背景 | 风暴教会战斗部队成员，性格暴躁但正直，擅长正面作战 |
| 途径 | 水手 |
| 初始序列 | 序列 8 暴气 |
| 晋升路线 | 序列 8 → 序列 7 风眷者 |
| 晋升条件 | 收集 2 份"风暴结晶"+ 成功执行 2 次"攻击"行动 + 扮演法加分（正面揭露污染源） |
| 专属卡牌 | "雷电之拳"（对污染源造成灵性伤害）、"风暴之怒"（强制 1 名玩家公开 1 张手牌）、"狂风屏障"（免疫 1 次攻击） |
| 被动技能 | "战斗本能"：P5 对决阶段首回合额外 1 行动点 |
| 复杂度 | 中（攻击性强，需要判断目标） |

### 5.3 塔罗会成员（调查者）

| 维度 | 内容 |
|------|------|
| 背景 | 以"格尔曼·斯帕罗"风格行动的独行侠，受愚者先生派遣参与调查 |
| 途径 | 占卜家 |
| 初始序列 | 序列 9 占卜家 |
| 晋升路线 | 序列 9 → 序列 8 小丑 |
| 晋升条件 | 收集 2 份"占卜材料"+ 成功执行 3 次"信息获取"行动 + 扮演法加分（成功预言 1 次） |
| 专属卡牌 | "灵视"（查看 1 张公共线索的隐藏信息）、"纸人替身"（免疫 1 次指认惩罚）、"命运丝线"（改变 1 次投票结果） |
| 被动技能 | "隐秘行动"：交互卡牌对他人使用时，对方无法反制 |
| 复杂度 | 高（技能灵活，需要策略判断） |

### 5.4 教会医生（调查者）

| 维度 | 内容 |
|------|------|
| 背景 | 教会医疗部门成员，负责处理尸体和检测污染，性格冷静 |
| 途径 | 收尸人 |
| 初始序列 | 序列 8 掘墓人 |
| 晋升路线 | 序列 8 → 序列 7 通灵者 |
| 晋升条件 | 收集 2 份"安魂香料"+ 成功执行 2 次"净化"行动 + 扮演法加分（救助 1 名高污染玩家） |
| 专属卡牌 | "死亡感知"（检测 1 名玩家是否被污染）、"尸体语言"（获取 1 条额外线索）、"安魂仪式"（降低 1 名玩家的污染度） |
| 被动技能 | "医学知识"：污染检定获得 +1 加成 |
| 复杂度 | 中（辅助向，需要判断团队需求） |

### 5.5 极光会渗透者（污染源）

| 维度 | 内容 |
|------|------|
| 背景 | 真实造物主信徒，伪装成教会支援人员潜入调查队伍 |
| 途径 | 窥秘人 |
| 初始序列 | 序列 8 野法师 |
| 晋升路线 | 序列 8 → 序列 7 炼金术士（堕落方向） |
| 晋升条件 | 收集 2 份"亵渎石片"+ 成功执行 2 次"破坏"行动 + 扮演法加分（成功误导 1 次） |
| 专属卡牌 | "亵渎之言"（增加 1 名玩家的污染度）、"伪造线索"（放置 1 条虚假线索）、"真实造物主低语"（推进仪式进度 5%） |
| 被动技能 | "伪装大师"：被指认时，有 50% 概率反制成功 |
| 复杂度 | 高（需要平衡伪装与推进） |

### 5.6 失控边缘者（污染源）

| 维度 | 内容 |
|------|------|
| 背景 | 原为教会成员，因晋升失败处于失控边缘，立场摇摆不定 |
| 途径 | 不眠者（变异） |
| 初始序列 | 序列 8 梦魇（失控） |
| 晋升路线 | 序列 8 → 序列 7 梦魇（暴走）或 序列 7 梦魇（恢复） |
| 晋升条件 | 分支 A（暴走）：收集 2 份"疯狂低语"+ 污染度≥50% → 暴走<br>分支 B（恢复）：收集 2 份"纯净灵性"+ 被救助 2 次 + 扮演法加分（如执行守护行为）→ 恢复（中等难度） |
| 专属卡牌 | "噩梦降临"（强制 1 名玩家跳过 1 回合）、"理智崩溃"（自身污染度 +20%，对 1 名玩家造成灵性伤害）、"残存意志"（降低自身污染度 10%） |
| 被动技能 | "失控波动"：每 2 回合随机获得 1 张额外卡牌（可能有利或有害） |
| 复杂度 | 极高（双面性，可被拉回或彻底堕落） |

## 6. 角色与阵营绑定

| 角色 | 阵营 | 绑定方式 |
|------|------|---------|
| 老值夜者 | 调查者 | 固定 |
| 代罚者军官 | 调查者 | 固定 |
| 塔罗会成员 | 调查者 | 固定 |
| 教会医生 | 调查者 | 固定 |
| 极光会渗透者 | 污染源 | 固定 |
| 失控边缘者 | 污染源 | 固定（但可被拉回调查者阵营） |

**失控边缘者特殊机制**：
- 初始为污染源阵营
- 若满足"恢复"晋升条件，可转换为调查者阵营
- 转换后获得调查者胜利条件，但保留部分污染源能力

## 7. 序列晋升机制

### 7.1 晋升条件

| 条件类型 | 说明 | 示例 |
|---------|------|------|
| 材料收集 | 收集特定数量的晋升材料 | 2 份"安眠草药" |
| 行动完成 | 成功执行特定类型的行动 | 2 次"守护"行动 |
| 扮演法加分 | 执行与角色名相符的行为（非必要） | 保护队友、成功预言等 |

### 7.2 晋升效果

| 效果 | 说明 |
|------|------|
| 能力解锁 | 获得新的专属卡牌（序列 7 级别） |
| 数值提升 | 灵性值上限 +2，污染抗性 +1 |
| 被动增强 | 原有被动技能效果提升 |
| 视觉标识 | 角色卡边框变化，提示其他玩家 |

### 7.3 晋升时机

- 玩家可在 P1/P3 调查阶段的自己回合内申请晋升
- 系统检查条件，满足则立即晋升
- 每局限晋升 1 次，整局最多晋升 1 次（序列 8→7 或 9→8）

## 8. 角色首发与扩展计划

| 阶段 | 角色 | 说明 |
|------|------|------|
| MVP 首发 | 老值夜者、代罚者军官、塔罗会成员、极光会渗透者 | 4 个角色，覆盖 3 条途径，平衡测试友好 |
| V1.1 扩展 | 教会医生、失控边缘者 | 增加辅助向和混乱向角色 |
| V2.0 扩展 | 观众途径角色、猎人途径角色、仲裁人途径角色 | 扩展途径覆盖，增加新阵营类型 |
| V3.0 扩展 | 序列 6 级别角色、多序列可选角色 | 增加深度和重玩价值 |

## 9. 平衡风险标注

| 角色 | 风险类型 | 说明 | 缓解策略 |
|------|---------|------|---------|
| 塔罗会成员 | 强度过高 | "命运丝线"改变投票结果可能过强 | 限制使用次数（每局 1 次），增加灵性消耗 |
| 极光会渗透者 | 隐蔽性过强 | "伪造线索"可能严重干扰调查 | 虚假线索有可检测特征，教会医生可识别 |
| 失控边缘者 | 不可预测性 | 随机卡牌可能产生极端局面 | 随机卡牌池预先筛选，避免破坏性过强的卡 |
| 代罚者军官 | 攻击性过强 | P5 对决阶段可能碾压其他角色 | 限制攻击卡牌对洁净者无效（防误伤） |

## 10. 与 D1/D2/D5 的联动

| 联动文档 | 联动点 |
|---------|-------|
| D1 单局流程 | 角色能力在 P1/P3 调查阶段和 P5 对决阶段生效；晋升在调查阶段进行 |
| D2 剧情背景 | 角色身份标签直接对应 D2 设定的组织成员；途径与 D2 力量体系一致 |
| D5 阵营胜利 | 角色与阵营绑定；失控边缘者可转换阵营影响胜利判定 |
