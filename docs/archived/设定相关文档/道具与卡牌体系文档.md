# 道具与卡牌体系文档 — 「值夜者档案：贝克兰德大雾霾」

> 本文档定义游戏的卡牌分类、效果模板、获取机制与使用代价。采用"专属核心 + 公共牌库"混合构建，灵性消耗与污染风险双重代价，封印物体系提供高风险高回报体验。

---

## 1. 卡牌体系概览

| 维度 | 内容 |
|------|------|
| **分类结构** | **行动卡**（一次性效果）、**装备/道具卡**（持续 buff/debuff）、**封印物卡**（强大效果 + 显著副作用） |
| **构筑方式** | **混合制**：开局持有专属核心卡（3-5 张）+ 游戏过程中从公共牌库补充（通用/途径共享） |
| **打出代价** | **混合制**：基础消耗灵性值；强力/禁忌卡牌增加污染度 |
| **稀有度** | 普通（灰）、稀有（蓝）、史诗（紫）、封印物（金） |

## 2. 卡牌分类详述

### 2.1 行动卡 (Action Cards)
一次性使用的卡牌，打出后进入弃牌堆。

| 子类 | 描述 | 示例 |
|------|------|------|
| **调查** | 获取线索、探索地点 | "灵性追踪"：获取 1 条私人线索 |
| **交互** | 影响其他玩家状态 | "审讯"：迫使目标展示 1 张手牌 |
| **技能** | 角色能力的具象化，消耗灵性 | "梦境穿刺"：对目标造成 2 点灵性伤害 |
| **事件** | 触发特定游戏事件或结算 | "突发雾霾"：所有玩家本回合调查行动失效 |

### 2.2 装备/道具卡 (Equipment Cards)
装备后持续生效，直到被替换、破坏或主动丢弃。占用装备栏位（通常 1-2 个）。

| 子类 | 描述 | 示例 |
|------|------|------|
| **防具** | 提供防御、抗性 | "夜视护目镜"：免疫 1 次"黑暗"类卡牌效果 |
| **饰品** | 提供被动加成 | "银制怀表"：每回合开始时额外恢复 1 点灵性 |
| **消耗品** | 虽名为道具，但效果即时，类似行动卡，归类于此为 lore 服务 | "净化药水"：立即降低 10% 污染度，卡牌消失 |

### 2.3 封印物卡 (Sealed Artifact Cards)
具有极强效果，但伴随严重的**负面副作用**（Side Effect）。副作用通常在每回合结束时或打出时自动触发。

| 等级 | 描述 | 风险 | 示例 |
|------|------|------|------|
| **3-xxx** | 低风险，副作用可控 | 轻微污染增加/资源消耗 | "3-012 锈蚀之剑"：攻击+2，持有者每回合灵性 -1 |
| **2-xxx** | 高风险，副作用致命 | 显著污染增加/强制行为/生命流失 | "2-049 万能钥匙"：可打开任何封印，但持有者每轮需进行意志检定，失败则失控 |
| **1-xxx** | 极高风险，MVP 暂不开放 | 可能导致游戏直接结束/角色死亡 | "1-XXX 0-08 羽毛笔"：改写现实（待定） |

## 3. 获取与构筑机制

### 3.1 初始手牌（P0 阶段）
每个角色开局获得：
1.  **专属核心卡**：3 张（从角色专属池中固定或随机选取）。
2.  **通用起手牌**：3 张（从公共牌库随机抽取）。

### 3.2 游戏内获取（P1/P3 阶段）
*   **调查行动**：成功调查地点可从公共牌库抽取 1-2 张卡牌。
*   **事件奖励**：完成特定事件或达成里程碑获得特定卡牌（如封印物）。
*   **交易/交互**：玩家之间可通过卡牌交换机制交换手牌（需双方同意）。

### 3.3 公共牌库构成
公共牌库包含：
*   **通用卡牌**：所有角色可用。
*   **途径卡牌**：仅限对应途径角色使用（抽到但非对应途径角色无法打出，可保留或弃置）。
*   **封印物**：极低概率出现在公共牌库中，或通过特定"遗迹探索"事件获得。

## 4. 消耗与代价机制

### 4.1 灵性值 (Spirituality)
*   **定义**：释放卡牌的能量资源。
*   **初始值**：角色基础灵性 + 序列加成（通常 10-15 点）。
*   **恢复**：通过"休息"行动、道具卡牌或特定事件恢复。
*   **消耗**：绝大多数行动卡、技能卡打出时需消耗灵性。

### 4.2 污染度 (Corruption)
*   **定义**：接触禁忌知识或使用禁忌力量的代价。
*   **增加源**：
    *   打出带有【禁忌】标签的卡牌（如封印物、某些强力技能）。
    *   处于被污染区域（P3 阶段特定地点）。
    *   遭受污染源攻击。
*   **阈值后果**：
    *   **低污染 (<30%)**：无影响。
    *   **中污染 (30%-60%)**：每回合受到 1 点灵性伤害。
    *   **高污染 (>60%)**：每回合需进行理智检定，失败则跳过回合或失控。

## 6. 卡牌数据结构建议

```typescript
interface Card {
  id: string;
  name: string;
  type: 'ACTION' | 'EQUIPMENT' | 'ARTIFACT';
  subtype?: 'INVESTIGATION' | 'COMBAT' | 'BUFF' | ...;
  rarity: 'COMMON' | 'RARE' | 'EPIC' | 'SEALED';
  cost: {
    spirituality?: number; // 灵性消耗
    corruption?: number;   // 污染增加
    health?: number;       // 生命/理智消耗
  };
  effect: {
    target: 'SELF' | 'TARGET' | 'ALL' | 'AREA';
    description: string;
    value?: number;
  };
  sideEffect?: {
    description: string; // 仅封印物
    trigger: 'ON_DRAW' | 'ON_HOLD' | 'ON_PLAY';
  };
  tags: string[]; // 如 ['NIGHTMARE', 'SEALED', 'TABOO']
}
```

## 7. 与 D1/D3 的联动

| 联动文档 | 联动点 |
|---------|-------|
| D1 单局流程 | P1/P3 调查阶段是主要抽牌/获取装备时机；P5 对决阶段是大量消耗手牌/使用封印物的时机 |
| D3 角色体系 | 角色晋升解锁新专属卡牌（如序列 8→7 获得强力技能卡）；角色被动技能影响卡牌消耗或效果 |
| D5 阵营胜利 | 污染源阵营通过打出禁忌卡牌推进仪式进度；调查者通过净化/防御卡牌阻止仪式 |
