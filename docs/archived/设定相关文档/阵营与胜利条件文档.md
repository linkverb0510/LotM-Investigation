# 阵营与胜利条件文档 — 「值夜者档案：贝克兰德大雾霾」

> 本文档定义游戏的阵营结构、胜利条件、失败条件。无淘汰机制，投票为最终卡牌对决积累优势，个人任务与阵营胜利混合判定。

---

## 1. 阵营系统设计目标

| 维度 | 目标 |
|------|------|
| 核心原则 | 无淘汰制，推理投票为最终对决积累优势 |
| 阵营划分 | 调查者阵营 vs 污染源阵营（混合威胁） |
| 胜利判定 | 个人任务积分 + 阵营胜利加分 |
| 复杂度控制 | 胜利条件简洁可记，隐藏信息层级清晰 |

---

## 2. 阵营结构方案

### 方案 A：双阵营 + 个人任务（推荐）

| 维度 | 内容 |
|------|------|
| 阵营划分 | **调查者**（洁净者）vs **污染源**（混合威胁） |
| 隐藏信息 | 玩家仅知自己身份，不知他人阵营 |
| 胜利判定 | 个人任务完成（积分）+ 阵营胜利（加分） |
| 博弈特点 | 经典隐藏身份 + 社交推理，污染源需伪装，调查者需推理 |
| 3-6 人适配 | 3-4 人：1 污染源；5-6 人：2 污染源 |
| 实现复杂度 | 低 |
| 平衡复杂度 | 中（需调节污染源数量和能力） |
| 新手理解成本 | 低 |

### 方案 B：三阵营 + 摇摆立场

| 维度 | 内容 |
|------|------|
| 阵营划分 | **调查者** vs **极光会** vs **外神信徒** |
| 隐藏信息 | 玩家知自己阵营，不知他人；失控边缘者可摇摆 |
| 胜利判定 | 各阵营独立胜利条件，失控边缘者选择阵营后结算 |
| 博弈特点 | 三方博弈，污染源之间也可能敌对 |
| 3-6 人适配 | 5-6 人适用，3-4 人阵营过少 |
| 实现复杂度 | 中 |
| 平衡复杂度 | 高 |
| 新手理解成本 | 中 |

### 方案 C：个人胜利为主 + 阵营加成

| 维度 | 内容 |
|------|------|
| 阵营划分 | 无明确阵营，每人独立 |
| 隐藏信息 | 每人独立任务，可能冲突或一致 |
| 胜利判定 | 纯个人任务积分排名 |
| 博弈特点 | 高度自由，但缺乏阵营对抗感 |
| 3-6 人适配 | 全人数适用 |
| 实现复杂度 | 低 |
| 平衡复杂度 | 高（任务平衡难） |
| 新手理解成本 | 中 |

**推荐方案 A**：结构清晰、易于实现、适合朋友局 MVP，保留阵营对抗感的同时通过个人任务增加策略深度。

## 3. 方案 A 详细设计

### 3.1 阵营定义

| 阵营 | 成员 | 核心目标 |
|------|------|---------|
| **调查者** | 洁净者、塔罗会成员 | 完成调查任务，阻止仪式 |
| **污染源** | 极光会渗透者、外神污染者、失控边缘者 | 推进仪式，完成个人目标 |

### 3.2 隐藏信息层级

| 信息类型 | 调查者可见 | 污染源可见 |
|---------|-----------|-----------|
| 自己身份 | ✓ | ✓ |
| 他人身份 | ✗ | ✗ |
| 自己污染度 | ✓（0） | ✓（>0） |
| 他人污染度 | ✗ | ✗ |
| 个人任务 | ✓ | ✓ |

### 3.3 投票作用机制（P2/P4 讨论阶段）

投票不淘汰任何人，但产生三重影响：

| 影响类型 | 正确指认污染源 | 错误指认洁净者 |
|---------|--------------|--------------|
| **资源** | 调查者获得线索卡/灵性值/强力卡牌 | 投票者失去资源，被指认者获得资源 |
| **信息** | 揭示污染源的部分特征或任务方向 | 揭示被指认者的洁净证明，污染源获得掩护 |
| **仪式进度** | 仪式进度 -10% | 仪式进度 +5% |

### 3.4 胜利判定

#### 阵营胜利条件

| 阵营 | 胜利条件 |
|------|---------|
| 调查者 | P5 结束时仪式进度 < 50% 且至少 1 名污染源被正确指认 |
| 污染源 | P5 结束时仪式进度 ≥ 50% 或未被正确指认 |

#### 个人胜利条件（示例）

| 角色类型 | 个人任务示例 | 积分 |
|---------|-------------|------|
| 洁净者 | 收集 3 条关键线索 | 3 分 |
| 洁净者 | 成功指认 1 名污染源 | 5 分 |
| 洁净者 | 阻止仪式完成 | 10 分 |
| 极光会渗透者 | 收集 2 种仪式材料 | 3 分 |
| 极光会渗透者 | 误导调查 2 次 | 5 分 |
| 外神污染者 | 使 2 名玩家污染度上升 | 5 分 |
| 塔罗会成员 | 收集 3 条情报上报愚者 | 5 分 |
| 失控边缘者 | 污染度控制在阈值以下 | 3 分 |

#### 最终排名计算

```
最终得分 = 个人任务积分 + 阵营胜利加分（调查者胜利+5，污染源胜利+8）
```

### 3.5 P5 卡牌对决机制

P5 阶段玩家使用 P1-P4 积累的资源进行对决：

| 资源类型 | 来源 | P5 作用 |
|---------|------|--------|
| 线索卡 | P1/P3 调查、P2/P4 投票正确 | 提供能力加成或仪式控制 |
| 手牌 | 抽牌、交互获得 | 直接对决卡牌 |
| 灵性值 | 休息、卡牌效果 | 施放高序列能力 |
| 污染度 | 事件、投票错误、污染源技能 | 污染源转化为力量，调查者视为负面 |

**对决流程**：
1. 按回合顺序，玩家使用卡牌/能力争夺仪式控制权
2. 每轮结算仪式进度变化
3. 仪式进度归零则调查者胜利，达到 100% 则污染源胜利
4. 达到最大回合数时，按进度判定胜负

---

## 4. 失败条件与提前结束

| 条件 | 触发时机 | 结果 |
|------|---------|------|
| 仪式完成 | 仪式进度 ≥ 100% | 污染源阵营胜利，游戏提前结束 |
| 全员污染 | 所有调查者污染度超过阈值 | 污染源阵营胜利，游戏提前结束 |
| 仪式阻止 | 仪式进度 ≤ 0% | 调查者阵营胜利，游戏提前结束 |
| 最大回合 | P5 达到最大回合数 | 按当前仪式进度判定胜负 |

---

## 6. 复杂度标注

| 维度 | 评级 | 说明 |
|------|------|------|
| 实现复杂度 | 低-中 | 状态机管理清晰，投票/资源/仪式进度均为简单数值 |
| 平衡复杂度 | 中 | 需测试污染源数量、投票权重、卡牌强度 |
| 新手理解成本 | 低 | 阵营二元对立，胜利条件明确，个人任务可选理解 |

---

## 7. 与 D1 流程的联动

| D1 阶段 | D5 联动机制 |
|---------|-----------|
| P0 集结 | 分配阵营身份和个人任务 |
| P1/P3 调查 | 收集线索卡（P5 资源），污染度累积 |
| P2/P4 讨论 | 投票指认 → 资源/信息/仪式进度变化 |
| P5 对决 | 使用积累资源进行卡牌对决，仪式进度决定胜负 |
| P6 结算 | 个人积分 + 阵营加分 = 最终排名 |
