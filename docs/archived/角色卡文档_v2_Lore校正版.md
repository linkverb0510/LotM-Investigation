# 角色卡文档 v2（Lore 校正版）

> 本文档用于吸收外部《角色卡文档_v2》的优点：人物关系密度、旧案压力、案件张力与余波感。
> 同时校正其中与《诡秘之主》原著不兼容的组织、途径、序列和幕后逻辑问题。

---

## 一、这轮修订的核心原则

### 1. 不打散你已经喜欢的戏剧骨架

保留：

- 艾德温与戴芙琳之间压抑而克制的长期关系
- 塞西莉亚面对家族与真相的撕裂
- 奥斯顿面对组织逻辑与现场判断的矛盾
- 莱尔处在“只传递，不站队”的灰色中介位置
- 伊莱亚斯对危险知识的靠近
- 旧教堂旧案与当前东区事件的呼应

### 2. 只重写会伤到原著根基的部分

重点重写：

- 赫密斯教团相关表述
- 赫密斯共鸣碑设定
- 亚瑟、格里芬、伊莱亚斯的途径与真相功能
- 莱尔手上残卷的来源说明

## 三、亚瑟·霍尔文（校正版）

### 1. 新定位

亚瑟不是“窥秘人途径序列8 解密师”。

校正后：

- `错误途径·序列7 解密学者`
- 霍尔文家族成员
- 慈善项目实际运作者之一
- 石碑残卷与错误祷文的幕后重组者

### 2. 剧情功能

他在案件里的作用不再是“一个想靠石碑实验晋升的人”，而是：

- 接手了格里芬留下的错误抄录与研究笔记
- 用解密学者的能力把缺页、碎句、残卷和错误记录拼出一套足够可用的近似仪式
- 借慈善项目把灵性导引节点悄悄布入东区现实空间
- 同时拖慢教会和调查者识别真正核心异常物的速度

### 3. 新动机

亚瑟最初确实带有求知与晋升欲望，但那不足以解释他为何跨过最后一步。

校正版动机统一为：

- 他早年曾接触过带有污染的第四纪文献、残句或祷文抄本；
- 这份污染没有立刻让他失控，而是在他后来的研究中不断以“启示”“完成它”“你只差最后一步”的形式回响；
- 当他接触到格里芬的笔记和石碑相关残卷后，这种旧污染与极光会 / 真实造物主的授意链条发生呼应；
- 他最终相信自己不是在主动制造灾难，而是在完成一项必须被继续的启示。

### 4. 与塞西莉亚的关系张力

这条线应保留并强化。

关键不是“家族里出了坏人”，而是：

- 亚瑟在家族中的公共形象仍可体面、稳妥、负责；
- 他对慈善项目的投入在表层甚至是真的；
- 塞西莉亚越能看见他的真诚部分，就越难把他简单归类成“纯粹的恶”。

这会让她的撕裂感更成立：

> 她不是在揭发一个从一开始就假的人，而是在揭发一个曾经真实、后来被错误知识与授意扭曲的人。

## 四、格里芬·索恩（校正版）

### 1. 新定位

格里芬统一修正为：

- `隐者途径·序列9 窥秘人`
- 年轻、冒进、把“看懂一点点”误以为“已经足够靠近真相”的低序列研究者

### 2. 他在案件中的真正职责

格里芬不是幕后主谋，也不该和伊莱亚斯、亚瑟抢同一层技术位置。

他最合适的戏剧位置是：

- 最早发现石碑的人
- 最早抄录祷文的人
- 最早把危险知识从地下室表面带出来的人
- 最早为此付出失控代价的人

### 3. 他的死亡意义

格里芬的死要保留，但解释要更准确：

- 不是普通仪式事故
- 而是“低序列窥秘人错误接近被污染知识闭环”的典型结局

他留下的意义不是“研究结束了”，而是：

> 他把一份不完整、已经被扭曲的知识遗产交给了更有能力也更危险的人。

## 五、伊莱亚斯·温特（校正版）

### 1. 组织与身份口径调整

伊莱亚斯保留为：

- `隐者途径·序列7 巫师`
- 与摩斯苦修会研究链、外围知识网络或独立研究协助体系有关

不建议继续写成“知识教会巫师”这种容易把教会、途径和组织混为一谈的表述。

更合适的表达是：

- `与摩斯苦修会研究链有联系的巫师`
- `受邀协助的独立神秘学研究者`
- `掌握摩斯苦修会式研究方法的外围协助者`

### 2. 他在剧情里的职责

伊莱亚斯承担的不是“最先发现”也不是“真正操盘”，而是：

- 在调查现场识别被篡改的祷文结构
- 判断关键物件到底是核心还是诱饵
- 第一个意识到“这不是单纯的封印物泄漏，而是一套被错误补全的仪式闭环”的人

### 3. 他的危险感来源

他的危险感不来自阵营，而来自“知识欲”。

要保留他身上这层《诡秘之主》味道很重的张力：

- 他不是想毁掉谁
- 他只是极难在真相还差最后一步时停下来
- 而这恰恰让他最容易被石碑拖进错误知识的逻辑里

## 六、莱尔手上那份残卷（校正版）

### 1. 删除的旧说法

不再写：

- 第四纪赫密斯教团仪式残卷
- 来自不存在的赫密斯教团资料链

### 2. 新来源口径

莱尔手上的残卷，统一改写为：

- 与 `赫密斯祷文石碑` 相关的第四纪赫密斯语仪式残页
- 经过多轮抄写、误译、拼接与转手
- 在地下非凡者圈、文献黑市以及摩斯苦修会外围研究链之间流动过

### 3. 为什么危险

危险不在于它是“完整秘本”，而在于：

- 它是不完整的
- 它曾被错误理解过
- 它已经和石碑本体的影响链发生过相互印证

也就是说，这份残卷像一把“会把人带到近似正确答案、但越靠近越危险”的钥匙。

### 4. 莱尔的戏剧价值因此更强

这样一改，莱尔就不仅仅是在运送一份神秘文件，而是在运送：

- 一份各方都不敢公开认领的危险知识
- 一份谁拿在手里，谁就可能把案子推向不同方向的半成品真相

这会更贴合他“只传递、不站队，但越来越不确定自己究竟在替谁工作”的张力。

---

## 七、艾德温 × 戴芙琳关系线（保留并强化）

### 1. 这条线不需要修，只需要更清楚地知道它为什么有用

它的价值不在于“浪漫”，而在于：

- 给案件增加真实的人际代价
- 让旧案与现案不只通过档案相连，也通过人相连
- 让艾德温的稳场冲动、戴芙琳的过度靠近真相，都有更私人的危险理由

### 2. 建议保留的表达方式

- 不公开说破
- 通过默契、偏袒、失态、回避与结局余波去显现
- 让这段关系成为“讨论时会让两人都不再完全专业”的触发点，而不是摆在桌面上的恋爱标签

## 八、术语统一要求

以下词汇必须统一替换：

| 旧写法 | 新写法 |
|---|---|
| Hermes Society / 赫密斯教团 | 删除 |
| 赫密斯共鸣碑 | 赫密斯祷文石碑 / 错译祷碑 |
| cataloguing | 编目 / 归档鉴定 |
| ritual nodes | 仪式节点 / 灵性导引节点 |
| 阅读者（指格里芬） | 窥秘人 |
| 解密师（指亚瑟） | 解密学者 |

---

## 九、对后续角色文案的写法要求

以后凡是写这几个角色，必须遵守以下思路：

- `艾德温`：不是“老好人”，而是背着旧案阴影、总想先稳住局面的值夜者老手
- `戴芙琳`：不是“死亡系专家”，而是最接近死者真相、也最容易被余波困住的人
- `莱尔`：不是“中立送信员”，而是危险知识在灰色地带流通的承载者
- `奥斯顿`：不是“武力执行者模板”，而是组织命令和现场正义之间的受压者
- `塞西莉亚`：不是“会读心的贵族”，而是被体面、家族与真相撕开的观察者
- `伊莱亚斯`：不是“知识担当”，而是明知再看一眼会危险，还是会再看的人
- `亚瑟`：不是“升级反派”，而是被错误知识与授意逐步牵引的幕后操盘者

---

## 十、结论

这次角色修订的核心，不是让文案更长，而是让每个人的“剧情张力来源”更符合《诡秘之主》的世界：

- 危险知识会诱人靠近
- 真相常被组织性地延迟或遮蔽
- 角色的毁灭很少来自单一恶意，更多来自好奇、责任、体面、忠诚与错误启示的缠绕

只要这一层成立，角色卡就不再只是“能力壳”，而会自然长出真正能支撑调查、讨论和余波的内容。
