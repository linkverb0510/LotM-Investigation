# 卡牌库：仪式类 (Ritual Cards)

> **适用阶段**：P3-P5 (主要活跃期)
> **作用**：暗中增加 Boss 威胁、获取特殊恩赐、加速自身变异。

## 机制说明
*   仅限邪恶或高污染玩家高效使用。
*   **副作用**：会显著增加 Boss 威胁度，可能导致危机提前爆发。

## 核心卡牌列表
1.  **真实造物主的注视** (渗透者)：
    *   效果：Boss 威胁 +15。
    *   收益：获得 2 灵性 + 1 个隐藏恩赐 (用于决战)。
2.  **梦魇暴走** (边缘者)：
    *   效果：Boss 威胁 +10。
    *   收益：自身回复 2 灵性 (缓解高污染带来的灵性枯竭)。
