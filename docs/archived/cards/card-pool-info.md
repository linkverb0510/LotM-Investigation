# 卡牌库：调查类 (Info Cards)

> **适用阶段**：P1 (迷雾搜集), P2 (异变初现), P3-P5 (通用)
> **作用**：获取线索、探查 Boss 弱点、查看玩家状态。

## 机制说明
*   调查类卡牌不会增加污染。
*   获取的“线索”可用于解锁高级情报或后续阶段的特殊行动。

## 核心卡牌列表
1.  **守夜记录** (值夜者)：获取 1 线索 + 查看 Boss 威胁。
2.  **灵视** (魔术师)：查看玩家污染区间 或 Boss 弱点。
3.  **现场勘查** (代罚者)：获取 1 线索 (Boss 狂暴时 +1)。
4.  **低语解读** (渗透者)：获取 1 线索 (隐藏身份掩护)。
5.  **亡者问诊** (医生)：查看 Boss 弱点 或 玩家隐藏状态。
6.  **梦境碎片** (边缘者)：获取 1 线索。
