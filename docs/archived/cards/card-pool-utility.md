# 卡牌库：功能/防御类 (Utility Cards)

> **适用阶段**：P1-P5 通用 (核心生存手段)
> **作用**：降低污染、减少 Boss 威胁、免疫环境伤害、资源回收。

## 机制说明
*   应对“公共危机”的主要手段。
*   能力非消耗品，打出后进入弃牌堆，洗牌后可再次使用。

## 核心卡牌列表
1.  **安魂祷词** (值夜者)：自身污染 -10，Boss 威胁 -5。
2.  **纸人替身** (魔术师)：免疫一次环境伤害 (弃牌代价)。
3.  **雷霆震慑** (代罚者)：Boss 威胁 -10 (强力控场)。
4.  **亵渎伪装** (渗透者)：免疫 Boss 针对性锁定。
5.  **防腐药剂** (医生)：指定一名目标污染 -10。
6.  **通灵者手记** (医生)：从弃牌堆回收一张牌。
7.  **占卜家的筹码** (魔术师)：洗牌并抽牌。
