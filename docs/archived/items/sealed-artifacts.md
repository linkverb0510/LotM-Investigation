# 道具库：封印物 (Sealed Artifacts)

> **设计原则**：MVP 阶段不引入原著具体编号 (如 2-087)，避免考据错误。仅保留外观特征与功能描述。
> **获取方式**：P2-P4 阶段的高阶调查行动掉落，或初始自带。

## 封印物列表

### 1. 封印物·暗红色怀表 (值夜者相关)
*   **外观**：一块停摆在 3 点 15 分的黄铜怀表，表壳上刻有黑夜女神的圣徽，指针偶尔会逆向转动。
*   **功能 (护盾/免疫)**：激活后，持有者在 3 秒内免疫所有环境伤害与 Boss 技能（如“亡者凝视”）。
*   **代价**：使用后，持有者本轮无法打出其他卡牌。

### 2. 封印物·风暴教会徽记 (代罚者相关)
*   **外观**：一枚被雷电烧焦的银色徽记，握在手中会有轻微的麻痹感。
*   **功能 (护盾)**：获得一层“风暴庇护”，抵消下一次受到的伤害。
*   **特性**：若用于抵消“雷电”类伤害，效果翻倍。

### 3. 封印物·占卜家的筹码 (魔术师相关)
*   **外观**：三枚刻有神秘符文的金属筹码，表面流转着灰雾般的光泽。
*   **功能 (资源/洗牌)**：将弃牌堆的一张牌强制洗入牌库底，并立即抽一张牌。
*   **特性**：可以用来回收关键的防御牌。

### 4. 封印物·通灵者手记 (医生相关)
*   **外观**：一本沾满黑色污渍的羊皮日记，书页上写满了疯子的呓语，但仔细辨认能看出是某种解剖记录。
*   **功能 (回收)**：允许持有者从弃牌堆中精确检索并回收一张 Utility 牌。
*   **代价**：使用后污染度 +5。
