## 3. 维护规则

1. 同主题只保留一个主版本，旧版本移入 `docs/archived/`
2. 当前只要涉及玩法定义，优先以调查模式主文档体系为准
3. 未来如进入对决模式规划，应单独建立文档，不与调查模式混写
4. 调试日志、临时问题清单、一次性草图默认不长期保留
