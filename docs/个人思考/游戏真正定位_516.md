# 定位问题

1.  我最初开发的目的是—做出一款以“诡秘之主”为ip的，朋友之间可以通过网站远程在线游玩的，融合了社交推理 + 卡牌对战的一款游戏；但关于这样一款游戏，就在开发过程中同时存在如下几个问题：
   1. 第一，想满足游戏对于“诡秘之主”原著气氛和内容等等的还原——这就意味着我需要将剧情/叙事做得比较圆满优秀，并将其恰当地融入游戏过程当中——但“社交推理”和“卡牌对战”两种类别的游戏，通常剧情都并不重要，也往往不是设计重点；
   2. 第二，想同时满足社交推理还有卡牌对战，这就导致游戏的体验极易出现割裂—虽然我想通过在一轮游戏的前期、中期两个大阶段做好社交推理，而在一轮游戏的最后阶段以“最终决战”的形式来体现卡牌对战，但目前后者尚未设计并且也极其容易出现割裂；
   3. 第三，由于codex你过于关注后端/引擎侧的问题，而不会站在玩家角度来审查前端以及游戏过程，同时对我的意图理解存在偏差、理解不全面等问题（对于原著《诡秘之主》也存在类似问题），这就导致当前：
      1. 游戏前端展现了过多的信息，例如从玩家角度看，里面出现了大量只需要设计师考虑的内容—例如截图中所示的，这样的地方还有很多
      2. 对于剧情、人物设计都很粗浅，在一局游戏过程当中，完全无法体会到我在之前的对话中所生成与设计出来的大量有关于人物、剧情的文档，进一步就无法让玩家产生对于游戏的代入感；
