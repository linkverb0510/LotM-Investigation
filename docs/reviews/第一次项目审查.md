## 二、P0 — 致命问题（阻塞完整一局）

### P0-1: 玩家状态浅拷贝导致竞态条件
- **位置**：`engine.ts` 多处 `players: [...state.players]`
- **根因**：数组浅拷贝，内部 player 对象仍为引用，后续直接修改 (`player.spirituality -= x`) 破坏不可变性
- **影响**：多玩家并发提交时状态撕裂，bug 不可复现
- **严重性**：线上对局可能随机崩溃

### P0-2: 胜利判定逻辑缺失
- **位置**：`GameState.winnerPlayerIds` 字段存在但从未填充
- **影响**：游戏进入 `finished` 后无法判定胜负，无结算画面

### P0-3: 基础 UI 不完整
- **缺失**：
  - Boss 威胁条 HUD（引擎有 `boss.threatLevel` 但前端未展示）
  - 剧情抉择弹窗 (`StoryChoiceModal`)
  - 结算画面（胜负结果展示）
  - 讨论阶段 UI（当前仅"投票确认继续"，无推理/发言/指认交互）
- **影响**：玩家无法看到关键游戏状态，体验断裂

## 三、P1 — 架构缺陷（影响扩展性）
