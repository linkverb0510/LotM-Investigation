# 核心案件主文档 — 贝克兰德东区异常死亡与地下仪式案

## 1. 案件定位

这是调查模式第一案，也是当前所有角色、行动卡与 Storylet 的共同舞台。

它的职责不是讲完一部长篇故事，而是提供一条足够稳的“案件骨架”，让不同角色、不同隐情、不同真相候选都能挂上去。

## 2. 案件不变量

无论本局变体如何变化，以下内容始终成立：

- 时间：第五纪 1352 年秋，贝克兰德东区，雾霾异常加重的数日之后
- 表面事件：连续异常死亡引发官方和教会警觉
- 异常特征：
  - 死者神情极度扭曲
  - 部分尸体呈现不合理的干涸或冰冷
  - 某些证词互相冲突，像被改写过
- 隐蔽核心：地下空间或旧建筑内部存在超凡干预痕迹
- 结构目标：玩家必须通过两轮调查和两轮讨论，判断如何处置这场异常

## 3. 公共案件简报

适用于 P0 公共开场的统一案情：

> 1352 年秋，贝克兰德大雾霾笼罩东区。  
> 一周内已有数起异常死亡被秘密上报，死者身份各异，却都在死前表现出短暂失常、梦呓和祷告式低语。  
> 由于事态可能牵涉超凡污染，你和另外几名身份各异的协助者被临时召集，要求在今夜之前查明真相，并阻止局势进一步扩散。

## 4. 关键地点

| 地点 | 作用 | 常见线索 |
|---|---|---|
| 东区租屋 | 第一案发现场 | 死者随身记录、焦痕、异味、祷文残页 |
| 小教堂侧室 | 组织压力与净化资源来源 | 祷告记录、神职人员证词、封印物暂存信息 |
| 地下煤仓/旧防空室 | 核心异常空间 | 仪式痕迹、污染源头、关键物件 |
| 警署档案间 | 官方版本的材料 | 尸检报告、失踪页、封存命令 |
| 临时停尸房 | 通灵与尸体线索来源 | 不完整尸检、灵性残响、错置身份信息 |

## 5. 关键证物

| 证物 | 类型 | 说明 |
|---|---|---|
| 烧焦祷文残页 | 公共线索 | 暗示异常仪式与宗教文本被混用 |
| 缺页尸检报告 | 公共线索 | 指向有人事后干预记录 |

## 7. 案件真相基准

本案的完整真相链定义在权威源文档中：

> 权威源：`docs/设定相关文档/权威源/全案真相基准文档_修订版.md`

核心概要：
- **核心异常物**：错译祷碑 —— 第四纪赫密斯语教派遗留的仪式装置，至少 2 级封印物
- **幕后推动者**：亚瑟·霍尔文 —— 错误途径·序列 7 解密学者，被极光会/真实造物主污染链植入的"被授意感"驱使
- **核心机制**：石碑精神同化场 → 灵性引导标记 → 居民行为模式的潜意识改写
- **组织博弈**：黑夜教会（制度性遮蔽）+ 风暴教会（独立情报与封存权争夺）+ 摩斯苦修会（知识封锁）+ 极光会污染链（暗处授意）

本案件采用「唯一的必然」原则：不存在多个候选真相，所有 Storylet、线索、结局分支均从同一真相基准派生。

## 8. 可变要素与重玩价值

一局游戏的重玩价值由以下变体维度保证（而非更换案件真相）：

| 变体维度 | 说明 |
|----------|------|
| **隐情包分配** | 每局从 6 个隐情包中为角色随机或预设分配，决定个人任务与压力源 |
| **关系包激活** | 每局激活 2-3 组角色关系包，改变讨论动力与信任结构 |
| **角色调查路线** | 不同玩家选择不同调查目标与途径行动，导致线索发现顺序与完整度差异 |
| **骰子检定结果** | D20 随机性使同一行动产生不同档位的结果（天启/成功/勉强/失败/灾厄） |
| **收束决策** | 集体决策在「封印/破坏/揭露/崩坏」四条路径中选择，导向三种结局分支 |
| **个人议程完成度** | 每个角色的隐藏议程是否完成，影响 P6 个人结局文本 |

## 9. 适合在本案中表达的《诡秘之主》元素

- 值夜者与教会程序
- 代罚者的强制介入风格
- 通灵、梦境、仪式干预等超凡调查方式
- 序列能力带来的代价与风险
- 封印物不是战利品，而是危险工具
- 组织之间未必完全互信

## 10. 结局方向

本案采用三种收束结局（详见权威源文档 §4）：

| 结局 | 前提条件 | 叙事基调 |
|------|----------|----------|
| **完美收束·真相大白** | 调查组正确识别亚瑟为主谋、莱尔成功阻断残卷关键页、石碑激活被中断、艾德温推动旧案公开 | 真相被揭露，代价被支付。没有一个完美的结局，但至少这一次真相没有被封回抽屉 |
| **妥协收束·表面的和平** | 石碑被控制但旧案未完全公开、亚瑟未被正式审判、各组织达成止损默契 | 体面是最昂贵的沉默。案件被压住了，名字被保住了，但调查组每个人都知道有什么东西停在封签后面 |
| **崩坏收束·失控的代价** | 调查判断错误或内部分歧导致行动延误、石碑进入更高功率激活态、精神同化场大面积扩散 | 崩坏不是结束，而是那句低语变得更安静、更广泛、更不肯离开的开始 |

三种结局下每个角色都有独立的结局独白（已在 Storylet 池的 `seed-ending-xxx` 中实现）。
