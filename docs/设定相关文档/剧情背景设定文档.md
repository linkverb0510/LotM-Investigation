# 剧情背景设定文档 — 「值夜者档案：贝克兰德大雾霾」

> 本文档定义游戏的世界观背景、核心冲突、玩家身份框架及叙事驱动方式，深度绑定《诡秘之主》原著第五纪贝克兰德时期的剧情与设定。

---

## 1. 剧情背景设计目标

| 维度 | 目标 |
|------|------|
| 核心目标 | 为 3-6 人房间制单局对战提供一个自洽、有张力、可支撑多轮推理与博弈的剧情背景 |
| 氛围目标 | 深度还原《诡秘之主》第五纪贝克兰德时期的神秘学氛围、社会矛盾、组织博弈 |
| 玩法服务 | 背景必须能自然导出身份隐藏、信息博弈、合作与背叛并存的机制 |
| 原著还原 | 直接使用原著中的组织名称、人物、地点、途径/序列、非凡物品、历史事件等，最大化情怀还原度 |

## 2. 背景方案：「值夜者档案：贝克兰德大雾霾」

### 2.1 时代与舞台

**时间线**：第五纪 1352 年秋 — 贝克兰德大雾霾事件前后

**地理背景**：鲁恩王国首都贝克兰德
- **东区**：贫民窟，工厂林立，空气污浊，居民多为工人和贫民。大雾霾期间死亡人数最多，怨魂与污染最为严重。
- **大桥区**：中产阶级居住地，有贝克兰德大学、医院、剧院等设施。
- **皇后区**：贵族和富商居住区，豪宅、花园、私人俱乐部林立。
- **霍尔伯爵府邸**：正义小姐奥黛丽的家族宅邸，塔罗会早期成员聚会地之一。
- **圣赛缪尔教堂**：永恒黑夜教会在贝克兰德的主教堂，值夜者小队驻地所在。
- **贝克兰德地下墓穴**：古老的地下通道和墓穴系统，邪教徒和非凡者活动的隐秘场所。

**时代特征**：
- 工业革命鼎盛期，蒸汽机、工厂、铁路普及，但环境污染严重
- 鲁恩王国实行君主立宪制，议会政治与贵族势力并存
- 正神教会（永恒黑夜、风暴之主、知识与智慧之神）影响力巨大
- 非凡者世界暗流涌动，各大组织和序列途径的博弈从未停止
- "扮演法"已被部分非凡者掌握，但教会仍倾向于传统晋升方式

### 2.2 核心历史事件：贝克兰德大雾霾

**事件背景**：
- 1352 年秋，贝克兰德遭遇罕见的浓雾天气，工厂排放的废气与自然雾气混合，形成持续数周的"大雾霾"。
- 雾霾中弥漫着工业污染、化学毒素和**灵性污染**，东区贫民大量死亡，死亡人数超过万人。
- 大量死者怨魂无法安息，徘徊于东区街道，形成了罕见的"怨魂聚集"现象。
- 各大教会派出非凡者处理危机，但雾霾的灵性成分异常复杂，暗示有多方势力在暗中推动。

**深层阴谋**：
- **极光会**（崇拜真实造物主）试图利用大雾霾中的怨魂和污染，完成一项"集体献祭仪式"，为真实造物主降临现实开辟通道。
- **外神"堕落母神"** 的信徒趁机在雾霾中散播"母神赐福"，试图将部分死者转化为"神孽"。
- **黄昏隐士会**（阿蒙相关）可能也在暗中观察和操纵局势，试图获取某种关键信息或非凡特性。
- 多方势力的介入使得大雾霾不仅是自然灾害，更是一场"灵性层面的战争"。

### 2.3 玩家角色设定

**玩家身份**：
玩家扮演一支由不同教会/组织派出的**联合调查小队**，受命进入贝克兰德东区调查大雾霾中的异常现象。小队成员来自不同背景，彼此之间并不完全信任。

**可能的成员来源**：
| 来源 | 组织 | 代表途径 |
|------|------|---------|
| 永恒黑夜教会 | 值夜者（Nighthawks） | 不眠者、收尸人 |
| 风暴之主教会 | 代罚者 | 水手、读风者 |
| 知识与智慧之神教会 | 机械之心 | 阅读者、窥秘人 |
| 塔罗会（秘密派遣） | 愚者先生麾下 | 占卜家、学徒、偷盗者等 |
| 军方/王室特使 | 鲁恩王国非凡事务部 | 仲裁人、猎人等 |

**具体角色示例（可直接使用原著设定）**：
| 角色 | 途径/序列 | 背景 |
|------|----------|------|
| 资深值夜者 | 黑夜途径·序列7 梦魇 | 经验丰富的老值夜者，负责稳定队伍和梦境搜证 |
| 代罚者军官 | 水手途径·序列7 航海家 | 风暴教会派来的执行支援，负责封锁、护送与强制介入 |
| 灰雾魔术师 | 占卜家途径·序列7 魔术师 | 被秘密派入现场的神秘学协助者，擅长真假痕迹与隐秘接触 |
| 教会通灵师 | 收尸人途径·序列7 通灵者 | 值夜者体系中的灵界专家，负责尸体处理和污染诊断 |
| 贵族心理医生 | 观众途径·序列7 心理医生 | 来自上流社交圈的观察顾问，擅长识别人心失衡与证词破绽 |
| 摩斯苦修会巫师 | 窥秘人途径·序列7 巫师 | 独立研究者，通过摩斯苦修会获得魔药，擅长仪式学和危险物件解析 |

### 2.4 核心冲突

| 冲突层 | 描述 |
|--------|------|
| **表层冲突** | 调查大雾霾中的异常死亡事件，追踪邪教徒，阻止仪式完成 |
| **深层冲突** | 小队成员或关键协助者中，可能有人背负极光会接触史、失控后遗症、外神污染或被"阿蒙"寄生等私密问题 |
| **内在冲突** | 每个角色有私密隐情与个人议程，可能与集体调查目标一致或冲突（如莱尔需销毁残卷而伊莱亚斯需研究它） |
| **环境冲突** | 东区地下错译祷碑的灵性辐射持续扩散，玩家调查越深入，承受的污染和精神同化风险越高 |

### 2.5 污染源设定（混合威胁）

一局游戏中可同时存在多种污染源，不同玩家可能受到不同力量的侵蚀：

| 污染源类型 | 侵蚀方式 | 行为特征 | 终极目标 | 原著关联 |
|-----------|---------|---------|---------|---------|
| **极光会接触者 / 渗透隐情** | 曾与真实造物主信徒发生接触，或被迫协助某次外围布置 | 行为未必从开局就显出敌意，但会在关键处置和线索选择上留下偏向 | 隐瞒接触史、误导调查方向，或在必要时协助仪式推进 | 极光会是原著中真实造物主的主要信仰组织，适合作为隐情包和幕后推动力量 |
| **外神污染者** | 在探索过程中接触了"堕落母神"或"原始月亮"的污染 | 理智逐渐丧失，行为出现异常模式，偶尔会无意识泄露"不该知道的信息"，可能开始崇拜"母神"或"月亮" | 将自身或他人转化为"神孽"，或打开现实裂缝引入外神力量 | 外神是原著中来自星空的至高存在，包括"堕落母神""原始月亮""门""错误"等 |
| **阿蒙寄生体** | 被"时之天使"阿蒙或祂的眷者寄生 | 平时表现正常，但在关键时刻可能突然展现出"窃取""欺诈"等能力，行为逻辑难以预测 | 窃取小队收集的关键非凡特性或信息，或完成阿蒙的某个实验 | 阿蒙是原著中最危险的存在之一，代表"错误"途径，擅长寄生和欺诈 |
| **失控边缘状态** | 因魔药消化不完全或晋升后遗症而处于理智松动状态 | 平时仍能正常协助调查，但在高压、低语或高风险接触下可能出现危险偏差 | 保住自我锚定，避免在关键节点成为异常进一步扩大的媒介 | 失控是原著中非凡者的终极威胁，适合作为状态包而不是公开角色 |

> **设计注记**：一局 3-6 人的游戏中，污染/敌对要素数量为 1-2 个（根据总人数调整），具体类型随机或房主预设。它们优先通过隐情包、状态包和幕后推动槽位进入本局，而不是直接以公开固定角色形式出现。

## 3. 世界观与设定细节

### 3.1 力量体系：途径与序列

**22 条途径（可直接使用原著名称）**：

| 途径组 | 包含途径 | 代表序列0 |

| 观众组 | 观众、秘祈人、耕种者 | 空想家 |
| 审判者组 | 审判者、战神、死神 | 审判者 |

**序列等级（9-0）**：
- 序列 9-7：低序列，基础能力，大多数非凡者的水平
- 序列 6-4：中序列，获得显著超凡能力，可担任小队核心
- 序列 3-1：高序列，半神级别，拥有领域级能力
- 序列 0：真神，途径的顶点

**魔药与扮演法**：
- 玩家角色通过服用魔药获得能力，魔药配方对应特定途径和序列
- "扮演法"是消化魔药的关键，必须扮演魔药名称所暗示的角色
- 消化完成后才能安全晋升下一序列，否则魔药残留会导致失控

| 概念 | 说明 | 游戏中的体现 |

| **神秘学仪式** | 需要特定材料、时间、地点的仪式 | 游戏中的关键机制，污染源试图完成的仪式 |

## 4. 信息揭示机制

### 4.1 初始状态

| 信息类型 | 玩家可见性 |
|---------|-----------|
| 自己的公开身份（途径/序列/组织） | 自己可见 |
| 自己的隐藏身份标签 | 自己可见 |
| 自己的个人任务 | 自己可见 |
| 他人的公开身份 | 所有人可见 |
| 他人的隐藏身份标签 | **不可见** |
| 他人的个人任务 | **不可见** |
| 系统总览（所有身份） | 仅房主/系统可见 |

### 4.2 逐步揭示方式

系统通过以下途径逐步泄露隐藏信息：

| 揭示途径 | 机制说明 |
|---------|---------|
| **调查线索卡** | 玩家在调查过程中可能获得指向某人异常行为的线索卡（如"发现某人与极光会联络的痕迹"） |
| **事件触发** | 特定事件发生时，污染源可能被迫暴露某些特征（如"雾霾中听到某人用赫密斯语祈祷"） |
| **玩家交互** | 通过卡牌交互（如"审讯""试探""共享情报""灵性检测"）可获取他人信息 |
| **污染度系统** | 污染源的"污染度"随游戏进程上升，达到阈值时自动暴露部分特征（如"眼睛变成纯黑色""说话时带有回音"） |
| **失控时刻** | 某名角色若承受了“失控边缘”状态包，在特定条件下可能突然行为异常，引起怀疑 |
| **灵性感知** | 特定途径（如占卜家、窥秘人）可感知他人的灵性波动异常 |
| **塔罗会联络** | 塔罗会成员玩家可通过"灰雾之上"机制获取额外信息或任务 |

## 5. 胜利条件

采用 **个人任务 + 阵营混合** 判定：

### 5.1 阵营胜利条件

| 阵营 | 胜利条件 |
|------|---------|
| **调查者阵营**（洁净者） | 成功完成主线调查任务 + 指认并封印/清除所有污染源 |
| **污染源阵营** | 完成各自的仪式/目标，或存活至调查时限结束，或使调查者阵营全员污染/失控 |

### 5.2 个人胜利条件

| 角色类型 | 个人任务示例 |
|---------|-------------|
| 值夜者/教会成员 | "收集 3 条关键线索""成功指认 1 名污染源""保护某 NPC 存活""阻止仪式完成" |
| 极光会接触者 / 渗透隐情 | "确保某件关键物件不被正确处置""误导调查方向 2 次""完成仪式前置步骤之一""存活至第 X 轮" |
| 外神污染者 | "使 2 名玩家污染度上升""在东区散播母神低语""将自身转化为神孽""存活至仪式完成" |
| 阿蒙寄生体 | "窃取 1 件关键非凡特性""欺诈 1 名玩家使其做出错误判断""完成寄生实验""存活并逃脱" |
| 塔罗会成员 | "收集 3 条情报上报愚者先生""保护某条线索不被破坏""完成愚者先生交代的秘密任务" |
| 失控边缘状态持有者 | "将污染度控制在 X 以下""保住自我锚定""在失控前完成某项任务""避免让某人发现你的异常" |

### 5.3 胜利判定优先级

1. 个人任务完成 → 获得个人胜利积分
2. 阵营胜利 → 获得阵营胜利加分
3. 最终排名 = 个人积分 + 阵营加分（允许个人任务完成但阵营失败的混合结局）

## 7. 风险点与缓解策略

| 风险类型 | 具体描述 | 缓解策略 |
|---------|---------|---------|
| **复杂度风险** | 混合污染源+个人任务+阵营胜利+原著设定可能导致规则过于复杂 | MVP 阶段先做单一污染源+简化个人任务，后续迭代扩展。提供"新手模式"和"进阶模式" |
| **平衡性风险** | 污染源与洁净者之间的力量对比难以把控 | 通过污染度系统、时限机制、线索卡动态调节，测试多轮参数 |
| **叙事脱节风险** | 背景设定与卡牌机制脱节，变成"贴皮狼人杀" | 确保每张卡牌的效果都能在背景中找到合理动机（如"魔药消化"对应自我强化，"灵性检测"对应信息获取，"阿蒙的欺诈"对应身份混淆） |
| **原著还原风险** | 过度还原可能导致未读过原著的玩家难以理解 | 提供独立于原著的简明背景介绍（游戏内教程/背景手册），同时保留深度还原内容供原著粉探索 |
| **版权风险** | 虽然是非盈利项目，但仍需注意合理使用边界 | 明确标注"基于《诡秘之主》世界观的同人游戏"，不用于商业用途，尊重原著作者爱潜水的乌贼 |

## 8. 推荐方案：MVP 背景框架

**「值夜者档案：贝克兰德大雾霾」作为 MVP 背景方案的理由：**

1. **原著还原度高**：直接使用贝克兰德大雾霾这一原著重要事件，可引用大量原著设定、人物、组织、地点
2. **结构清晰**：单一主线事件（调查大雾霾异常）+ 混合污染源 + 个人任务，规则边界明确，适合 MVP 收敛
3. **可扩展性强**：后续可增加多事件并行、更多污染源类型、更复杂的个人任务链、跨时间线剧情
4. **社交推理友好**：信息逐步揭示机制天然适合朋友局的讨论与博弈
5. **原创空间充足**：在原著框架内可自由设计卡牌、事件、角色
6. **技术实现可控**：状态模型围绕"调查进度""污染度""线索收集""仪式进度"展开，数据结构清晰

### MVP 阶段裁剪建议

| 保留 | 延后 |
|------|------|
| 单一主线事件（大雾霾调查） | 多事件并行/事件递进/跨时间线 |
| 1-2 种污染/隐情类型（如极光会接触史 + 失控边缘） | 阿蒙寄生体 + 外神污染者 |
| 简化版个人任务（每玩家 1 个） | 个人任务链+多任务并行 |
| 基础污染度系统 | 复杂理智值/灵性值/扮演法消化系统 |
| 3-4 条途径（不眠者、收尸人、占卜家、水手） | 完整 22 条途径体系 |
| 基础非凡物品（3-xxx 级别） | 2-xxx/1-xxx 级别强力封印物 |
| 圣赛缪尔教堂 + 东区贫民窟 2 个场景 | 全贝克兰德多场景切换 |
