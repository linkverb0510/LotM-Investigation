# 调查模式叙事状态与 Storylet 总表

## 1. 文档目标

把调查模式中的叙事真正嵌进系统，而不是只停留在背景文案。

本表回答两个问题：

1. 系统需要跟踪哪些叙事状态
2. 这些状态会触发哪些公共或私密事件

## 2. 状态分组总览

### 2.1 公共案件状态

| 状态名 | 来源 | 用途 |
|---|---|---|
| 案件阶段 | 阶段推进 | 决定事件池与文案语气 |
| 现场封锁等级 | 集体决策 / 压制动作 | 影响谁能接触地点、谁会被怀疑 |
| 地下仪式暴露度 | 搜证、异常事件、收束失败 | 决定收束阶段风险与真相揭露速度 |
| 组织压力 | 时间推进、错误决策、事件触发 | 影响讨论紧迫感与结局评价 |
| 公共恐慌度 | 异常事件、公开失控 | 影响行动限制与舆论风向 |

### 2.2 私密角色状态

| 状态名 | 可见性 | 用途 |
|---|---|---|
| 本局隐情 | 私密 | 定义个人顾虑与行为动机 |
| 关系包激活状态 | 私密或半公开 | 决定谁会因旧情、旧怨或旧案关系而失衡 |
| 与案件的私人关联 | 私密 | 触发角色专属事件 |
| 接触污染史 | 私密 | 决定诱导与失控风险 |
| 关键物件占有 | 私密或半公开 | 决定行动能力与怀疑来源 |
| 自我锚定状态 | 私密 | 决定抗污染与摇摆走向 |

### 2.3 行为状态

| 状态名 | 来源 | 用途 |
|---|---|---|
| 频繁主导发言 | 讨论行为 | 触发“出头者压力”类事件 |
| 反复回避说明 | 讨论与行动 | 触发更强怀疑与私密压迫 |
| 过度使用净化/仪式 | 出牌和能力 | 触发组织或超凡反应 |
| 经常独自行动 | 集体措施之外行动 | 触发跟踪、误会、私密机会 |
| 多次维护同一对象 | 讨论与行动 | 触发关系猜疑事件 |

### 2.4 结局状态

| 状态名 | 用途 |
|---|---|
| 真相是否被正确触及 | 决定结局质量 |
| 污染是否被真正控制 | 决定余波色调 |
| 是否发生错判 | 决定组织反应与角色命运 |
| 是否有人完成私密目的 | 决定个人结局分支 |
| 关键物件最终去向 | 决定案件是否埋下后患 |

## 3. Storylet 类型

| 类型 | 作用 | 例子 |
|---|---|---|
| 公共案件事件 | 推进公共叙事与压力 | “尸检报告缺失一页”“东区教堂钟声提前响起” |
| 角色私密事件 | 强化代入与个人冲突 | “你认出死者袖口上的缝线样式” |
| 行为反应事件 | 让系统回应玩家行为 | “你过于积极地要求搜查，让代罚者开始注意你” |
| 组织立场事件 | 强化组织程序和身份差异 | “教会内部命令要求优先保护封印物” |
| 结局余波事件 | 给一局收口 | “官方通报掩盖了真正死因，只留下冷冰冰的一句煤气中毒” |

## 4. 各阶段 Storylet 建议

### P0：案情简报

- 公共案件事件：
  - 东区雾霾与异常死亡简报
  - 官方/教会压力说明
- 私密事件：
  - 角色为何被派来
  - 本局隐情第一跳

### P1：第一轮行动

- 公共案件事件：
  - 现场第一批反常征兆
  - 关键地点被打开或被封锁
- 私密事件：
  - 某角色认出旧痕迹
  - 某角色被低语吸引
  - 某组关系开始被微弱唤醒
- 行为反应事件：
  - 单独接触尸体
  - 过早使用高风险手段

### P2：第一轮讨论

- 公共案件事件：
  - 案情会议开始
  - 第一批矛盾证词浮现
- 组织立场事件：
  - 某组织要求优先保护或优先处置某物

### P3：第二轮行动

- 公共案件事件：
  - 地下室、仪式痕迹、失控征兆进一步暴露
- 私密事件：
  - 私人关系被激活
  - 锚定开始松动
- 行为反应事件：
  - 反复隐瞒、主动带节奏、净化过量

### P4：第二轮讨论

- 公共案件事件：
  - 现场压力升级
  - 关键物件去向进入众人视野
- 组织立场事件：
  - 是否允许越权处置

### P5：收束阶段

- 公共案件事件：
  - 仪式或异常源头进入处置窗口
- 私密事件：
  - 某角色必须表态或背弃
- 结局前置事件：
  - 真相被揭露或被掩埋

### P6：余波结局

- 结局余波事件：
  - 官方记录版本
  - 教会内部版本
  - 角色个人命运版本

## 5. 样例 Storylet 块

### S-PUB-001 东区尸检报告缺页

- Scope: public
- Phase: P1 / P2
- Trigger: 至少一名玩家执行 `搜证` 成功，且现场封锁等级不高
- Event Content: 尸检报告的末页被人撕走，留下不自然的焦痕
- Results:
  - 新增公共线索 `报告缺页`
  - 解锁讨论问题“谁先接触过档案室”
- Design Intent: 让第一轮讨论围绕案件本体展开，而不是空泛怀疑

### S-PRI-004 梦中钟声

- Scope: private
- Phase: P3
- Trigger: 角色接触污染史为真，且本轮使用过净化或通灵类能力
- Event Content: 你在极短的恍惚里听见教堂钟声提前敲响，仿佛在催促某个早已开始的仪式
- Results:
  - 你获得私密提示“地下空间可能已被提前启用”
  - 你的自我锚定状态下降一档
- Design Intent: 用私密信息制造“知道更多但说出来会暴露”的张力

### S-REA-002 过度出头

- Scope: reactive
- Phase: P2 / P4
- Trigger: 同一玩家连续两次主导讨论并推动强制措施
- Event Content: 你的强势让一部分人安心，也让另一部分人开始怀疑你为何如此急切
- Results:
  - 该玩家获得半公开标签 `风头太盛`
  - 下轮若再主动推动搜查，额外触发一次关系猜疑事件
- Design Intent: 让“带节奏”成为有风险的策略

## 6. 当前实现准备建议

- 当前先不要追求海量 Storylet
- 优先保证每个阶段至少有：
  - 1 个公共案件事件
  - 1 个角色私密事件
  - 1 个行为反应事件
- 先做“能跑出完整案件感”的小池子，再扩内容量
