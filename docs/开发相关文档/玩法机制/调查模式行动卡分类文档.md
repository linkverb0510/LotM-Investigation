# 调查模式行动卡分类文档

## 1. 文档目标

定义调查模式中卡牌的职责边界。

当前卡牌不再承担“独立战斗系统”功能，而是承担玩家介入案件、暴露自身、改变局势的动作语言。

## 2. 分类总览

| 分类 | 作用 | 典型风险 |
|---|---|---|
| 搜证 | 发现线索、读取痕迹、打开证据链 | 信息不完整、触发异常反应 |
| 接触 | 接近目标、人物、灵体或地点 | 被记录、被反制、被污染 |
| 压制 | 强制封锁、护送、打断、控制 | 引发反感、误判、越权 |
| 掩饰 | 抹除痕迹、制造伪证、隐藏状态 | 一旦穿帮后果更重 |
| 净化 | 降低污染、稳定局势、安抚异常 | 消耗灵性、可能掩盖真相 |
| 调度 | 调用组织资源、档案、权限、人手 | 留下立场痕迹、受上级约束 |
| 封印物 | 高风险换高收益的信息或处置能力 | 污染、反噬、真相提前失控 |

## 3. 各分类设计说明

### 3.1 搜证

#### 作用

- 获得公共线索
- 获得私密线索
- 验证或推翻已有说法

#### 适合的序列表达

- 梦境观察
- 通灵读取
- 痕迹回溯
- 直觉性发现

### 3.2 接触

#### 作用

- 与人物、证物、地点建立直接连接
- 打开特殊事件或风险通道

#### 适合的序列表达

- 私下交谈
- 纸偶替身接触
- 以祷告或仪式接近异常源

### 3.3 压制

#### 作用

- 强制中断危险过程
- 护送关键人
- 抢占关键物件或场所的控制权

#### 为什么战斗型序列需要它

因为调查模式中，风暴、战士、猎人等角色不应该靠打伤害存在，而应该通过“强制介入局势”体现压迫感和执行力。

### 3.4 掩饰

#### 作用

- 隐藏私密行为
- 制造信息错位
- 推迟真相暴露

#### 适合的序列表达

- 伪证
- 误导性叙述
- 替身与假痕迹

### 3.5 净化

#### 作用

- 压低污染
- 稳定角色或现场
- 为收束阶段争取空间

#### 设计注意

净化不应永远是纯正收益。  
过度净化可能遮蔽真相、耗尽关键资源，甚至引来组织质疑。

### 3.6 调度

#### 作用

- 调出档案
- 调动辅助人手
- 获取组织许可

#### 设计价值

这类卡能把《诡秘之主》的组织结构做进玩法，而不是只写在背景里。

### 3.7 封印物

#### 作用

- 以危险代价换取强力介入
- 打开正常调查手段触及不到的信息

#### 设计注意

- 必须高风险
- 必须叙事感强
- 必须有“为什么平时不乱用”的理由

## 4. 卡牌文本设计要求

- 先写“为什么能这样做”，再写“效果是什么”
- 尽量使用统一术语
- 不把过多边界条件塞进卡面主文本
- 调查模式中的卡牌说明优先让玩家理解“这张牌怎样改变案件局势”

## 5. 当前样例映射

| 角色 | 优先分类 |
|---|---|
| 资深值夜者 | 净化 / 搜证 / 调度 |
| 灰雾魔术师 | 掩饰 / 接触 / 搜证 |
| 代罚者军官 | 压制 / 调度 / 搜证 |
| 贵族心理医生 | 搜证 / 接触 / 掩饰 |
| 教会通灵师 | 搜证 / 净化 / 接触 |
| 神秘学顾问（巫师） | 搜证 / 封印物 / 接触 |

## 6. 当前设计禁区

- 不把调查模式行动卡写成标准战斗卡组
- 不让所有强卡都只提供数值收益
- 不让战斗型角色只能在“未来对决模式”里才有用
- 不让封印物退化成普通装备卡
