## 1. 设计目标

将「不同序列·不同能力」从文字背景变为**可操作的数值差异**，使玩家选择角色时感受到的不是「名字不同」而是「我能做到他做不到的事」。

参考游戏：
- **博德之门3**：六属性 + D20 检定 + 技能熟练项
- **极乐迪斯科**：技能检定驱动叙事分支，失败也有有趣的后果
- **漫野奇谭**：属性影响叙事选项的可用性

## 2. 属性体系

### 2.1 六属性定义

| 属性 | 英文标识 | 含义 | 典型行动 | 高属性角色 |
|------|----------|------|----------|-----------|
| **灵性** | `aura` | 非凡力量储备与灵性精度 | 通灵、占卜、封印物操作 | 艾德温(6)、戴芙琳(6) |
| **洞察** | `insight` | 看穿谎言、情绪、隐藏意图 | 证词分析、动机推理、社交识破 | 塞西莉亚(6) |
| **意志** | `will` | 精神韧性、抵抗侵蚀 | 梦境稳定、净化、自我锚定 | 艾德温(5)、戴芙琳(4) |
| **体质** | `physique` | 身体强韧、暴力执行 | 破门、压制、承受冲击 | 奥斯顿(6) |
| **诡诈** | `cunning` | 隐秘行动与信息操控 | 潜行、伪造、痕迹替换 | 莱尔(6) |
| **知识** | `lore` | 神秘学知识广度与深度 | 仪式解析、古文翻译、异常鉴定 | 伊莱亚斯(6) |

### 2.2 六角色完整属性

| 角色 | 灵性 | 洞察 | 意志 | 体质 | 诡诈 | 知识 | 总计 |
|------|:----:|:----:|:----:|:----:|:----:|:----:|:----:|
| 艾德温·莫里斯 | 6 | 4 | **5** | 3 | 2 | 3 | 23 |
| 莱尔·杜瓦尔 | 5 | 3 | 2 | 2 | **6** | 2 | 20 |
| 奥斯顿·雷文斯 | 5 | 2 | 4 | **6** | 1 | 1 | 19 |
| 塞西莉亚·霍尔文 | 5 | **6** | 3 | 1 | 3 | 3 | 21 |
| 戴芙琳·西蒙 | **6** | 4 | 4 | 2 | 1 | 2 | 19 |
| 伊莱亚斯·温特 | 5 | 5 | 3 | 2 | 1 | **6** | 22 |

**属性总分的差异是故意的**——艾德温作为经验最丰富的值夜者，整体能力最强。奥斯顿极端偏科，戴芙琳在特定领域无人能及。

### 2.3 专长

专长不提供被动加值——它在**特定情境下改变检定规则**：

| 角色 | 专长1 | 效果 | 专长2 | 效果 |
|------|-------|------|-------|------|
| 艾德温 | `旧案之眼` | 调查与旧案相似的线索时，**失败也获得模糊信息** | `梦魇凝视` | 梦境追溯时，可**重掷一次**（代价：双倍疲劳） |
| 莱尔 | `灰雾直觉` | 检定结果差 ≤2 时，消耗 1 灵性**重掷一次** | `纸人替身` | 首次大失败后果**转移为假痕迹** |
| 奥斯顿 | `风暴在前` | 体质检定**结果+1**；但非体质检定大失败时触发组织冲突 | `破门者` | 强制突入行动时，体质需求**-2** |
| 塞西莉亚 | `看穿人心` | 洞察检定**大成功**时额外获得隐情提示 | `社交之镜` | 讨论阶段可声明某人说谎——若正确获信任 |
| 戴芙琳 | `死者之声` | 通灵相关灵性检定**难度-2** | `灵界漫游` | 意志检定失败后可选「深入一层」再掷一次 |
| 伊莱亚斯 | `仪式学者` | 仪式结构知识检定**难度-2** | `禁忌条目` | 知识大成功时额外读到一个不该知道的事实（污染+2） |

## 3. 骰子系统

### 3.1 核心公式

```
掷骰: D20 (1-20)
最终结果 = D20 + 对应属性值 + 合作加值 (±0/+1/+2)
目标难度 = 基础难度 + 环境修正
```

### 3.2 五档结果

| 结果档位 | 判定条件 | 线索产出 | 代价 | 出现概率（属性=4,难度=12） |
|----------|----------|----------|------|--------------------------|
| **天启** | D20=20 **或** 总结果 ≥ 难度+8 | 完整线索 + 意外发现 + 难度永久降低 | 灵性消耗减半 | ~5% |
| **成功** | 总结果 ≥ 难度 | 完整线索 | 正常消耗 | ~45% |
| **勉强** | 总结果 < 难度 且 ≥ 难度-3 | 部分线索 + 方向提示 | 双倍灵性消耗 | ~15% |
| **失败** | 总结果 < 难度-3 且 ≥ 难度-6 | 模糊异常信号 | 灵性消耗 + 污染+1 | ~15% |
| **灾厄** | D20=1 **或** 总结果 < 难度-6 | 被污染的误导信息 + 反噬事件 | 灵性消耗 + 污染+2 + Storylet异常 | ~5% |

**关键设计原则**：灾厄不是「什么都没得到」——是「得到了一个错误的东西，而且你不知道它是错的」。

### 3.3 难度基准

| 难度标签 | 目标值 | 典型场景 |
|----------|:------:|----------|
| 简单 | 8 | 明显物理痕迹、普通档案、状态正常的证人 |
| 普通 | 12 | 大部分调查行动的基础难度 |
| 困难 | 16 | 石碑周边的灵性检定、深入梦境、被污染的灵体 |
| 极难 | 20 | 解读第十七段祷文、直接触碰石碑核心 |
| 传奇 | 24 | 在完全激活的精神同化场中保持自我 |

### 3.4 难度修正因子

```
基础难度（由调查目标决定）
  + 石碑周边（灵性辐射干扰）            +2
  + 当前压力 Tier ≥ 3                   +2
  + 当前压力 Tier ≥ 4                   +4（覆盖上条）
  + 角色污染度 ≥ 4                      +2
  - 角色持有相关物品（拓片/笔记）        -2
  - 已有角色成功调查同一目标             -2
  - 有合作辅助                          -2
  ────────────────────────────────────
  最终难度（上限 25，下限 5）
```

## 4. 行动-属性-检定映射

### 4.1 七类行动动词的属性绑定

| 行动类别 | 主检定属性 | 辅助属性 | 操作成本 | 典型产出 |
|----------|:----------:|----------|----------|----------|
| **搜证** | 洞察 | 知识(仪式线索)、意志(旧案) | 1灵性 | 公共/私密线索 |
| **接触** | 灵性 | 洞察(活人)、意志(灵体) | 1灵性 | 私密信息/关系触发 |
| **压制** | 体质 | 意志(精神压制)、灵性(封印物) | 2灵性 | 控制权/强制中断 |
| **掩饰** | 诡诈 | 知识(伪造仪式痕迹) | 1灵性 | 痕迹隐藏/假信息 |
| **净化** | 意志 | 灵性(灵性净化)、体质(物理净化) | 1灵性 | 降低污染/稳定 |
| **调度** | 知识 | 意志(旧档案)、体质(武力调度) | 1灵性 | 组织资源/档案 |
| **封印物** | 灵性 | — | 2灵性 | 高风险深层信息 |

### 4.2 六角色擅长/危险矩阵

| 角色 | 最擅长(≥5) | 危险区(≤2) | 典型风险 |
|------|-----------|-----------|----------|
| 艾德温 | 搜证(旧案)、净化 | 掩饰(2) | 他不会撒谎——一旦需要隐瞒，必然暴露 |
| 莱尔 | 掩饰、接触 | 压制(2)、意志(2) | 肉体对抗必败，扛不住精神冲击 |
| 奥斯顿 | 压制、体质搜证 | 知识(1)、诡诈(1) | 永远不要让他碰祷文或隐藏信息 |
| 塞西莉亚 | 洞察搜证、接触 | 体质(1)、封印物 | 纸片人；碰高危险物件等于自杀 |
| 戴芙琳 | 灵性接触、净化 | 压制(1)、诡诈(1) | 打不过任何人，也藏不住任何事 |
| 伊莱亚斯 | 知识搜证、封印物 | 体质(2)、诡诈(1) | 身体脆弱；好奇心让他更易被反噬 |

## 5. 合作检定

### 5.1 基础合作（同地点互补行动）

**触发条件**：两个角色选择同一地点 + 执行不同类别的行动

**效果**：
1. 双方各自独立检定，获得各自维度的信息
2. 检定完成后，系统自动生成一条「合成洞察」——融合两人发现的新结论
3. 合成洞察对双方均可见（私密信息）

**限额**：每轮每人最多参与 1 次合作

### 5.2 加值合作（辅助他人检定）

**触发条件**：辅助者与主检者位于同一地点 + 辅助者的行动类别可强化主检者

**辅助加值**：
| 辅助者对应属性 | 加值 |
|:------------:|:----:|
| ≥ 5 | +2 |
| 3-4 | +1 |
| ≤ 2 | +0 |

**风险**：若主检者大失败 → 辅助者也承受 1 点污染

### 5.3 辅助有效性映射

| 主检属性 | 有效辅助（+2） | 勉强有效（+1） |
|----------|--------------|--------------|
| 灵性 | 灵性（共鸣）、意志（稳定连接） | 知识 |
| 洞察 | 洞察（交叉验证）、知识（理论支撑） | — |
| 体质 | 体质（协力）、意志（精神威慑） | 诡诈 |
| 诡诈 | 诡诈（掩护）、洞察（警戒识别） | — |
| 知识 | 知识（合译）、洞察（异常识别） | 灵性 |
| 意志 | 意志（联合压制）、灵性（灵性引导） | — |

## 6. Storylet 检定扩展

### 6.1 接口设计

在 `InvestigationStoryletSeed` 中新增可选字段：

```typescript
interface InvestigationStoryletSeed {
  // ... 现有字段

  /** 检定配置——若无此字段，则该 Storylet 为纯叙事事件 */
  check?: {
    attribute: "aura" | "insight" | "will" | "physique" | "cunning" | "lore";
    baseDifficulty: number;
    coopAllowed: boolean;
    assistAttributes?: string[];
  };

  /** 五档结果文本变体——若无此字段，则降级为使用 textSeed + 结果标记 */
  results?: {
    revelation?: string;   // 天启
    success?: string;      // 成功
    partial?: string;      // 勉强
    failure?: string;      // 失败
    catastrophe?: string;  // 灾厄
  };
}
```

### 6.2 首轮改写的 Storylet

| Storylet | 检定属性 | 基础难度 | 为什么选它 |
|----------|:--------:|:--------:|-----------|
| `seed-public-salt-spread` 灰白圆弧 | 洞察 | 10 | 这是玩家首个「调查地点」场景——最适合引入检定 |
| `seed-public-missing-page` 尸检缺页 | 洞察 | 12 | 不同角色应看到缺页的不同线索层面 |
| `seed-public-watchman-contradiction` 证词矛盾 | 洞察 | 14 | 高洞察角色（塞西莉亚）应在此处展示优势 |
| `seed-public-salt-expansion` 盐痕扩散 | 灵性 | 14 | 石碑附近的灵性检定——引入压力修正 |
| `seed-public-second-body` 第二名死者 | 灵性 | 14 | 通灵者（戴芙琳）的核心场景 |

## 7. 数据结构

### 7.1 新增类型（schema.ts）

```typescript
/** 六属性 */
export type Attribute = "aura" | "insight" | "will" | "physique" | "cunning" | "lore";

/** 角色属性值 */
export interface CharacterAttributes {
  aura: number;
  insight: number;
  will: number;
  physique: number;
  cunning: number;
  lore: number;
}

/** 角色专长定义 */
export interface CharacterSpecialty {
  id: string;
  name: string;
  description: string;
  /** 效果触发条件（留白为被动生效，非空为玩家主动触发） */
  triggerHint?: string;
}

/** 五档检定结果 */
export type DiceResultTier = "revelation" | "success" | "partial" | "failure" | "catastrophe";

/** 检定配置（内嵌在 Storylet 中） */
export interface CheckConfig {
  attribute: Attribute;
  baseDifficulty: number;
  coopAllowed: boolean;
  assistAttributes?: Attribute[];
}

/** 检定结算结果 */
export interface CheckOutcome {
  tier: DiceResultTier;
  d20Roll: number;
  finalResult: number;
  difficulty: number;
  resolvedText: string;
  cluesGained: number;
  corruptionDelta: number;
  triggerEventId?: string;
}
```
