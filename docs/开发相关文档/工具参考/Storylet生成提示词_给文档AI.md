# Storylet 生成提示词

> **用途**：将此提示词发给生成「全案真相基准文档」和「角色卡文档」的 AI，令其基于那两份权威文档产出足够支撑一局完整游戏体验的 Storylet 池。
> **创建日期**：2026-05-17

---

## 背景说明

我们正在开发一款以《诡秘之主》贝克兰德为背景的多人在线调查推理游戏。当前主模式为「调查模式」——6 名玩家扮演来自不同组织、不同途径的固定角色，通过行动卡驱动调查、结构化讨论和集体收束，在一局 45-75 分钟的游戏中完成一起超凡案件的调查与处置。

当前核心案件：**贝克兰德东区异常死亡与地下仪式案**（详见你已生成的「全案真相基准文档_修订版」）。

已有两个权威文档作为唯一上游：
1. `全案真相基准文档_修订版.md` — 案件底层真相、组织博弈、结局分支
2. `角色卡文档_v2.md` — 6 个固定角色的完整设定、隐情、弱点、关系

**你的任务**：基于这两份文档，设计出足够数量、覆盖全流程的 Storylet（叙事事件），使得一局游戏中玩家能持续感受到剧情推进。

---

## 一、游戏流程简述（供参考）

一局游戏分 7 个阶段：

| 阶段 | 名称 | 时长 | 核心体验 |
|------|------|------|----------|
| P0 案情简报 | 进入角色、接收私密隐情 | 5min | "我是谁，我为什么被叫来，我最怕暴露什么" |
| P1 第一轮行动 | 使用行动卡介入案件现场 | 10-15min | 产出首批线索、留下可被讨论的行为痕迹 |
| P2 第一轮讨论 | 结构化案件会议 | 5-8min | 划定调查重点、产生第一个集体决定 |
| P3 第二轮行动 | 在压力下继续深入调查 | 10-15min | 更强的异常暴露、私人关系激活、组织压力显现 |
| P4 第二轮讨论 | 建立最终处置的信任链 | 6-10min | 决定谁执行收束、谁被隔离 |
| P5 收束阶段 | 封印/净化/揭露/失控 | 8-12min | 前面所有选择在此兑现 |
| P6 余波结局 | 复盘真相与角色命运 | 4-6min | 案件真相回顾 + 每个角色的个人结局 |

信息架构采用三层模型：
- **公共层**：所有玩家可见的案件线索、异常现象、集体决定
- **私密层**：仅当前玩家可见的角色隐情、私人发现、组织私下指令
- **调试层**：仅设计师可见（你不需关心）

## 二、Storylet 类型与格式

### 类型定义

| scope | 可见性 | 典型用途 |
|-------|--------|----------|
| `public` | 所有玩家可见 | 案件推进、异常暴露、新线索产出 |
| `private` | 仅 affectedRoles 中的玩家可见 | 角色私密发现、个人记忆闪现、组织私下指令 |
| `reactive` | 行为触发后半公开 | 系统回应玩家行为（如过度出头、反复回避） |
| `relationship` | 两个指定角色之间的互动 | 关系摩擦、旧情触发、被迫站队 |
| `ending` | 结局时展示 | 收束结果、角色命运文本 |

### phaseHint 对照

| phaseHint | 对应阶段 | 说明 |
|-----------|----------|------|
| `briefing` | P0 | 案情简报期 |
| `investigation_up` | P1 | 第一轮行动期 |
| `discussion_1` | P2 | 第一轮讨论期 |
| `investigation_down` | P3 | 第二轮行动期（案件压力升级） |
| `discussion_2` | P4 | 第二轮讨论期 |
| `resolution` | P5-P6 | 收束与结局期 |

### 输出格式

每条 Storylet 请按以下 JSON-like 结构输出（不需要真的写成 JSON，用 Markdown 表格或结构化段落均可，但要清晰标注每个字段）：

```
- id: "seed-{scope}-{简短英文标识}"
- scope: "public" | "private" | "reactive" | "relationship" | "ending"
- phaseHint: "briefing" | "investigation_up" | "discussion_1" | "investigation_down" | "discussion_2" | "resolution"
- title: "中文简短标题（6-10字）"
- source: "authority-case-v2"（公共事件） 或 "authority-roles-v2"（角色事件）
- triggerHint: "触发条件的自然语言描述"
- textSeed: "事件文本（40-80字，符合诡秘之主文风）"
- affectedRoles: ["role-01-edwin", ...]（仅 private / relationship 需要）
- relatedTruthMapIds: ["truth-xxx", ...]（关联的全案真相条目ID）
- designIntent: "为什么需要这条事件，它解决什么叙事问题"
```

## 三、需要你产出的内容

按以下六个类别逐一设计，每个类别说明目标数量、设计原则和需要解决的问题。

### 类别 A：公共案件事件（约需 5-7 条新建）

**已有**（不需要重新写）：
- 东区案情简报（P0 开篇）
- 灰白圆弧 / 地窖盐痕（P1）
- 相同的梦 / 集体噩梦（P2）
- 尸检缺页（P1）
- 被安排的路线 / 慈善点位网络（P3）

**需要你新建**：
1. **巡夜人证词矛盾**（P1）——某巡夜人的证词中出现自相矛盾的巡逻路线，他在无意识中提到了本不在他巡逻范围内的教堂街。这应揭示灵性引导标记对居民的间接影响。
2. **盐痕扩散**（P3）——回访地下室时发现盐痕范围已远超首次记录，它在自行生长。这是石碑进入不可逆加速态的中盘升级信号。
3. **第二名死者**（P3）——新尸体被发现，双手呈"非教会祷告手势"（双掌合十、指尖朝下），一位值夜者低声提到这种手势在第三纪元的异端记录中出现过。
4. **封印物异常**（P3）——多件来源不同的低阶封印物同时出现异常行为（罗盘指向教堂、安魂铃自鸣），揭示赫密斯铭文同源共振。
5. **另外 1-3 条你认为能丰富公共案件推进的事件**，如：居民精神状态的进一步恶化、教会内部对调查节奏的异议浮出水面、某条关键证物在传递过程中"意外丢失"等。

**设计原则**：公共事件应该是所有玩家都能讨论的共同基础。每条事件产出后，玩家应该能围绕它提出一个明确的讨论问题（如"谁有机会接触档案室？""为什么封印物会指向同一个方向？"）。

---

### 类别 B：组织立场事件（约需 3-5 条新建，scope = public 或 reactive）

**这是当前设计中最薄弱的环节。** 全案文档第三部分定义了三方组织博弈（黑夜教会怕旧案重翻、风暴教会想吞石碑、摩斯苦修会怕知识扩散），但这些在游戏中还未转化为可被感知的事件。

**需要你设计**：
1. **黑夜教会的沉默**（P3 或 P4）——调查深入到旧案层面时，值夜者角色（艾德温/戴芙琳）收到来自教会高层的模糊暗示："某些旧记录不需要被重新调阅。"这道指令措辞礼貌但意图明确。
2. **代罚者的独立行动**（P3 或 P4）——风暴教会通过私下渠道向奥斯顿重申优先封存指令，且暗示"不必等待黑夜教会的意见"。这应在公开层面露出端倪——如奥斯顿在某个关键节点突然要求封锁某区域，与他此前的配合姿态不一致。
3. **知识的封锁**（P3 或 P4）——伊莱亚斯在现场公开了仪式结构分析后，收到来自摩斯苦修会外围的警告："你今晚说的比你应该说的多。"这条警告不来自教会，来自一个更不透明的方向。
4. **另外 0-2 条你认为能体现组织博弈的事件**，如多个组织对同一件关键证物的控制权争夺、某个组织试图绕过调查组单独行动等。

**设计原则**：组织立场事件应让玩家真实感受到"我服务的组织并不完全支持我正在做的事情"。它不是背景描述，而是游戏内的实际约束——收到指令的角色面临"服从组织还是坚持调查"的选择。

---

### 类别 C：角色私密事件—中盘（约需 6 条新建，scope = private）

**已有**（不需要重新写）：
- 6 个角色的开场私密（P0），已覆盖：艾德温的旧案批注、莱尔的残卷指令、奥斯顿的封存命令、塞西莉亚的签名发现、戴芙琳的低语、伊莱亚斯的祷文识别。

**需要你新建**：每个角色 1 条中盘私密事件（P3 触发），在案件深入时揭示他们更个人的一面：

1. **艾德温**：当调查触及旧案细节时，触发他对三年前旧教堂事件的详细记忆——不是"报告被截留"这个事实（他已知道），而是那个被污染致死的老人、那份他重新提交但再无回音的补充报告。触发后让他面对一个选择：是继续追查旧案（可能再次目睹报告被压），还是接受这次可能也只是"又一次封存"。

2. **莱尔**：当他成功接触到残卷或关键页面时，触发他对委派者身份的怀疑——他发现委派者对石碑的了解远超正常情报范围，开始怀疑自己究竟是在"处理危险物"还是在"替某个更大的势力做知识封锁"。触发后，他在后续行动中可以选择是否向其他玩家透露部分委派者信息。

3. **奥斯顿**：当他被迫在公开讨论中为风暴教会的独立行动辩护时，触发他的个人记忆——他记起自己第一次出海时那个发疯跳海的年轻水手，记起自己加入代罚者是想"站在船翻之前就把危险砸碎的那一边"，而不是替人做政治筹码。触发后他面临：继续执行私下命令，还是在关键时刻违背它。

4. **塞西莉亚**：当调查证明亚瑟确实涉及案件时，触发她对童年的回忆——亚瑟小时候带她溜到后花园、在她第一次公开致辞时用眼神示意她"慢一点、别怕"。这段记忆与她现在手中的证据形成最残酷的对照。触发后，她在讨论中必须在"保护家族"和"揭露真相"之间做出一次明确表态。

5. **戴芙琳**：当她第二次听到灵界低语或接触与旧案相关的灵性残响时，触发她对旧教堂事件中那个十七岁学徒的完整记忆——学徒残响消散前最后一刻的表情（不是恐惧，而是一种茫然的困惑："为什么没有人告诉我还有危险"）。触发后，她获得一个选择：是否在这次案件中打破通灵者的规矩——允许自己的情绪介入通灵过程，以换取更清晰的残响信息，代价是自我锚定下降。

6. **伊莱亚斯**：当他深入分析祷文结构并即将触碰到石碑核心仪式逻辑时，触发他十六岁那年翻看父亲禁止他接触的封存笔记的记忆——笔记上那句"危险的不是知识本身，而是你对知识的好奇心比你想象中更难停下来"。触发后，他面临：继续深读（获得核心信息但承受知识反噬），或停在这里（保护自己但信息不完整）。

**设计原则**：中盘私密不是"给玩家塞背景故事"，而是"在案件推进的关键节点，让角色的个人历史成为玩家决策的砝码"。每条事件应附着一个需要玩家做出选择的时刻。

### 类别 D：角色私密事件—收束（约需 6 条新建，scope = private 或 ending）

在 P5 收束阶段，每个角色需要对真相做出一次个人反应。这些反应的文本可以在你已写的「全案真相基准文档」第四部分"三种结局的角色结局段落"中直接裁剪——但需要将它们转化为独立的 Storylet，而非嵌入结局长文本中。

**需要你设计**：每个角色 1 条收束私密，触发时机为 P5 收束阶段完成时。文本从全案文档的角色结局段落中裁剪为 50-80 字的独白（第一人称或近距离第三人称均可），并标注对应哪种结局（完美/妥协/崩坏）。

### 类别 E：行为反应事件（约需 4-6 条新建，scope = reactive）

**这是让"系统回应玩家行为"的关键层。** 当前设计中行为反应事件覆盖不足，导致玩家行为缺乏系统性反馈。

**需要你设计**：
1. **过度回避**——某角色连续两次在讨论中回避关键问题或拒绝说明信息来源时触发。产生半公开标签，下轮讨论中该角色的回避行为会受到其他玩家更明确的质疑。
2. **跨组织指令冲突**——当奥斯顿执行压制行动而艾德温要求继续调查，两方的组织立场在行动中直接碰撞时触发。产生公开事件，让所有玩家意识到"调查组内部的裂痕不只是个人之间的"。
3. **偏袒越界**——戴芙琳在讨论中为艾德温辩护的方式超出了专业判断范围时触发。产生半公开提示，让其他玩家开始怀疑两人之间存在超越同事的关系。
4. **知道得太多**——伊莱亚斯在讨论中揭示了超出常规调查能力范围的知识时触发。其他玩家（尤其是莱尔和奥斯顿）获得暗示："这个人知道的比他应该知道的多。"
5. **净化过量**——当值夜者或通灵者连续使用净化能力时触发。产生副作用提示——过度净化可能在掩盖某些本该被发现的污染痕迹。
6. **另外 0-2 条你认为有价值的行为反应事件**。

**设计原则**：行为反应事件的核心是"系统不评判对错，只是让玩家行为的后果变得可见"。它们本身不决定结局，但改变其他玩家对你的信任和怀疑。

### 类别 G：格里芬·索恩的跨角色线索网络（约需 3-5 条，scope 混合）

格里芬·索恩是全案文档中定义的关键人物——三年前唤醒石碑的自由非凡者、祷文抄录者、仪式实验失败而失控死亡的隐者途径序列 9。但他的故事目前几乎没有任何 Storylet 将其纳入游戏。

**需要你设计**：一组让不同角色通过不同渠道接触到格里芬碎片信息的 Storylet：

1. **艾德温的视角**：当他调阅值夜者旧档时，可能接触到三年前一份低阶非凡者失控死亡的记录——死者是一名走隐者途径的窥秘人，死因是仪式实验失败。记录没有提到石碑，但死者被发现的地点离旧教堂不远。

2. **伊莱亚斯的视角**：当他深入分析被篡改的赫密斯语祷文时，可能识别出篡改手法与十二年前某次失败实验的相似性——那次实验的参与者中包含一名隐者途径的窥秘人，实验记录被教会封存。

3. **戴芙琳的视角**：如果她在石碑附近的灵界中进行通灵探索，可能接触到一道不属于当前死者的、年代更久远的残响——一个年轻人在困惑和执念中消散前最后的灵性印记。

4. **另外 0-2 条你认为可以连接格里芬故事的其他路径**（如通过莱尔的地下非凡者网络、通过塞西莉亚的慈善项目参与者名单等）。

**设计原则**：格里芬的完整故事不应该被任何单一角色完整获取。他的存在应该是一幅被撕碎的画——不同角色捡到不同的碎片，只有在讨论中拼在一起才能看到轮廓。这既是对"拼图式调查"的强化，也是对不同角色信息获取渠道差异的展示。

## 四、写作要求

### 文风
- 符合《诡秘之主》的维多利亚时代+克苏鲁气质——克制、冷静、细节具体
- 不出现现代用语、网络用语、meta 评论
- 案件文件口吻参考值夜者报告风格：客观但偶尔泄露出记录者的不安
- 私密事件可更主观、更情绪化，但不能煽情——情感应通过细节传递，而非直接抒情

### 字数
- 公共事件 textSeed：50-80 字
- 私密事件 textSeed：60-100 字
- 行为反应事件 textSeed：30-50 字
