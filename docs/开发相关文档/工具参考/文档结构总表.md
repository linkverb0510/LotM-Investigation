## 4. 维护规则

1. 同主题只保留一个主版本，旧版本移入 `archived/`
2. 当前只要涉及玩法定义，优先引用调查模式主文档体系
3. 设计参考调研必须沉淀到 `game-design-references/`
4. 开发日志按日期命名：`开发文档_YYYYMMDD.md`
