# 调查模式产品定义文档

## 1. 模式定位

调查模式是本项目当前主模式。  
它不是纯狼人杀，也不是在社交推理外面再拼一层卡牌对战，而是：

> 一场发生在贝克兰德的超凡案件调查局。  
> 玩家扮演来自不同组织、不同序列、各有隐情的角色，借助行动卡、序列能力、公共讨论和集体处置，推动案件走向不同结局。

## 2. 玩家承诺

进入一局调查模式后，玩家应该得到以下承诺：

- 我不是抽象身份槽位，而是一个具体角色
- 我手里的牌不是普通战斗卡，而是我介入案件的方式
- 我每次发言都应该围绕案件、线索和处置展开
- 我在局中的选择会改变案件、关系和结局

## 3. 核心乐趣

### 3.1 案件乐趣

- 异常现象如何解释
- 证物和证词如何互相冲突
- 真相到底指向谁、什么组织、哪类污染

### 3.2 角色乐趣

- 固定角色带来代入感
- 可变隐情带来重玩价值
- 关系包让固定角色之间天然带有张力与历史
- 序列能力与组织权限提供不同介入方式

### 3.3 社交乐趣

- 不是随便聊天，而是案件会议中的博弈
- 通过发言争夺叙事主导权和集体资源分配
- 在信任与怀疑之间逼迫他人表态

### 3.4 叙事乐趣

- 玩家能在一局里经历完整的“开案、推进、异变、收束、余波”
- 结局会回答案件线和人际线，而不是只给出输赢

## 4. 与贴皮狼人杀的区别

| 维度 | 贴皮狼人杀式体验 | 调查模式目标 |
|---|---|---|
| 身份 | 更偏功能身份 | 固定角色 + 可变隐情 + 关系包 |
| 讨论 | 围绕“谁是坏人” | 围绕案件解释、行动授权、最终处置 |
| 卡牌 | 可有可无 | 直接承载序列能力与调查动作 |
| 高潮 | 投票放逐 | 收束阶段的处置与代价 |
| 世界观 | 靠皮肤与文案 | 靠组织程序、序列代价、封印物风险、污染事件 |

## 5. 当前模式边界

### 5.1 当前一定要做清楚的

- 单核心案件 + 高变体
- 至少 2 轮行动 + 2 轮讨论 + 1 次收束
- 公共事件、私密事件、行为反应事件
- 角色在调查模式中的独特职责

### 5.2 当前明确不做的

- 独立卡牌决斗终局
- 多案件并行池
- 跨局成长与大地图
- 对决模式的详细规则

## 6. 成功判断

如果调查模式做对了，玩家会这样描述它：

- “像在《诡秘之主》的世界里办一桩危险案子。”
- “每个人都像真有背景和隐情，不是只有身份和技能。”
- “讨论不是空聊，因为讨论完真的会改变谁能做什么。”
- “最后处理案件的时候，前面说过的话和做过的事都会回来算账。”
