# 固定角色池重构文档

## 1. 文档目标

把调查模式当前的角色体系，从“公开角色里直接混入敌对者”重构成：

- `固定公开角色池`
- `可变隐情包`
- `关系包`
- `Storylet 钩子`

这样做的目的，是让玩家先感受到“这是一支会共同进入现场的调查队伍”，再通过对局过程逐步看见背叛、污染、旧案与关系裂痕。

## 2. 重构原则

### 2.1 固定角色必须都能自然入队

固定角色池里的每个人，都要能被合理解释为“为什么今晚会被召集到这起超凡案件里”。

### 2.2 敌对性改由私密层承担

像 `极光会渗透者` 这类天然敌对身份，不再作为公开角色卡直接出现。  
它们转为：

- 隐情包
- 状态包
- 关系包
- 结局触发条件

### 2.3 原著气质高于表面花样

本轮的目标不是覆盖更多途径，而是让每个角色都像《诡秘之主》里的人。  
重点应放在：

- 组织生态
- 序列代价
- 现实职责
- 私密牵挂
- 危险知识带来的后果

## 4. 退出固定公开角色池的旧角色

### 4.1 极光会渗透者

退出原因：

- 作为公开固定角色时，很难自然进入“共同调查”的起点
- 玩家一看到名字就会默认这是敌对位，反而削弱推理
- 更适合作为本局隐情、真实阵营或幕后推动力量

新的承载方式：

- `极光会接触史` 隐情包
- `极光会渗透` 敌对包
- `真实造物主低语` 事件包

### 4.2 失控边缘者

退出原因：

- 作为公开固定角色时，问题从“谁有问题”直接变成“他本身就有问题”
- 会过早抢走讨论焦点
- 与梦魇、通灵者的世界观职责冲突较大

新的承载方式：

- `失控边缘` 状态包
- `晋升后遗症` 隐情包
- `理智松动` 行为反应事件

## 5. 为什么新增心理医生与巫师

### 5.1 心理医生

补位价值：

- 当前讨论内容空虚，很大原因是缺少“谁来解释人的反应”
- 观众途径天然适合案件会议、怀疑链、情绪失控与暗示操控
- 还能为后续恋人关系、隐瞒关系、旧案阴影提供更细腻的切口

### 5.2 巫师

补位价值：

- 当前角色池里缺少一个真正能承载“危险知识”和“仪式理论”的公开角色
- 窥秘人途径能自然把《诡秘之主》的神秘学、仪式学、物件风险做进玩法
- 比让敌对角色承担“神秘知识生产”更稳、更可复用

## 6. 与案件和讨论机制的关系

这套固定角色池不是为了“职业分工好看”，而是为了给讨论和剧情提供真实内容。

| 角色 | 最自然的讨论内容来源 |
|---|---|
| 梦魇 | 旧案、秩序、梦中审问、谁在失衡 |
| 魔术师 | 哪条痕迹是假的、谁故意留下烟雾 |
| 航海家 | 谁该被封锁、谁该被护送、谁不该单独行动 |
| 心理医生 | 谁在撒谎、谁在表演、谁是真的恐惧 |
| 通灵者 | 死者最后状态、尸体与现场是否对得上 |
| 巫师 | 仪式痕迹、封印物风险、异常现象的结构解释 |
