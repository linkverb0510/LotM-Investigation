# 角色在调查模式中的职责映射表

## 1. 文档目标

把当前固定角色池从“能用的角色设定”转成“在案件局里有明确职责和明确话语来源的人物”。

每个角色至少要回答：

- 他公开看起来负责什么
- 他私下最怕什么
- 他擅长怎样介入案件
- 他在讨论中能推动什么
- 他的风险和代价是什么

## 2. 固定角色映射

| 角色 | 公开身份职责 | 私密隐情方向 | 调查优势 | 讨论杠杆 | 风险 / 代价 |
|---|---|---|---|---|---|
| 资深值夜者 | 现场稳定、梦境搜证、秩序维护 | 旧教堂事件旧案报告与值夜体系沉默；与通灵者存在不便公开的长期牵连 | 梦境搜证、稳场、旧案交叉核对、保护关键人 | 以资历、程序知识和旧案经验争取话语权与调查节奏 | 过度稳局可能延后真相，也可能因私人牵挂失去克制 |
| 灰雾魔术师 | 神秘学协助、隐秘接触、异常痕迹处理 | 持有不进入正式记录的残卷回收任务；可能牵涉更高层知识封锁链 | 识别伪证、转移注意、接触隐秘线索、真假痕迹处理 | 能用“不完整但关键”的信息改变叙事方向 | 过度诡诈会迅速失去信任 |
| 代罚者军官 | 封锁现场、护送目标、强制中断危险行为 | 持有风暴教会的高危封印物优先回收私令 | 封锁、护送、打断危险接触、推动措施落地 | 能把会议结论立刻转成现场行动 | 误判会把局面推向更糟，也更容易被指责越权 |
| 贵族心理医生 | 精神安抚、证人评估、贵族与教会之间的社交协调 | 霍尔文家族与慈善项目实际负责人亚瑟的私人牵连 | 情绪侧写、识别谎言结构、判断谁在表演 | 能解释“谁为什么这样说”，让讨论不再停留在空泛猜疑 | 过度介入会被视作在操控会议 |
| 教会通灵师 | 尸体处理、灵界追索、污染诊断 | 旧教堂学徒死亡的愧疚；与艾德温的关系会影响判断 | 从死者和残留灵性中读出信息、区分案情本体与外部干扰 | 以专业判断影响他人信任和处置判断 | 接触死灵过深会更易被污染，也更难保持专业距离 |
| 神秘学顾问（巫师） | 仪式解析、异常物件辨识、神秘学结构分析 | 通过摩斯苦修会外围接触过危险知识；对真相有强烈靠近冲动 | 解构仪式、识别假核心、判断异常结构 | 能给出高价值的结构解释，决定哪条真相线更可信 | 知识反噬明显，越接近真相越容易失衡 |

## 3. 旧公开角色的新归属

当前不再把以下内容作为公开固定角色：

| 旧角色 / 旧概念 | 现在的归属 |
|---|---|
| 极光会渗透者 | 隐情包 / 敌对包 / 极光会污染链条 |
| 失控边缘者 | 状态包 / 晋升后遗症包 / 行为反应事件 |

原因是它们更适合作为“变化层”，而不是开局就公开摆在桌面上的身份。

## 4. 序列类型到调查职责的映射

| 序列倾向 | 在调查模式中的职责 |
|---|---|
| 调查 / 感知型 | 识别真假、提前发现隐患、打开私密信息通道 |
| 操控 / 误导型 | 改写叙述、调换证据、影响怀疑走向 |
| 战斗 / 强制型 | 破门、护送、封锁、压制、抢占物件控制权 |
| 仪式 / 神秘型 | 净化、通灵、短时稳定、触碰更危险信息 |
| 心理 / 社交型 | 读取情绪、打断伪装、改变会议判断节奏 |
| 知识 / 结构型 | 解释神秘学逻辑、识别假核心、定位真相结构 |

## 5. 角色设计检查单

如果未来新增固定角色，至少要检查：

- 是否有清晰公开身份职责
- 是否有足够推动案件的调查动作
- 是否能在讨论中形成不同于其他角色的话语价值
- 是否有符合《诡秘之主》气质的代价
- 是否至少能挂 1 条私密隐情
- 是否至少能承载 1 条关系包

## 6. 与未来对决模式的边界

本表只服务调查模式。

后续如果进入对决模式规划，需要为每个角色额外补：

- 对决模式的能力包
- 对决模式中的资源节奏
- 对决模式中的胜利贡献方式
