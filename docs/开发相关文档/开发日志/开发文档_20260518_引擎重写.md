# 开发文档 2026-05-18 · 引擎重写

## 开发需求
废弃旧 engine.ts（legacy 卡牌对战原型），新建 investigation-engine.ts 作为调查模式主引擎。将 v2 角色、属性、D20 检定、Storylet 全部接入核心游戏循环。

### 引擎核心设计
- **Internals 模式**：GoldenPath + GameState 通过 WeakMap 管理，不对前端序列化
- **卡牌适配层**：InvestigationCardSeed → FrontendCard 映射，前端无需关心 v2 数据结构
- **不可变状态**：所有状态更新通过浅拷贝，不直接 mutate
- **自动结算**：applyTurnAction 在全员行动后自动调用 resolveActionRound；applyVote 在全员投票后自动推进阶段

### 已知限制
- MVP 前端尚无调查目标选择（targetPicker），所有行动卡直接打出
- 讨论阶段仅支持投票推进，不支持文本聊天
- 私密 Storylet 文本暂不在前端展示（仅日志显示公共文本）
- 旧 engine.ts 保留为历史参考
