# 线索动态变质机制 (Dynamic Clue Mutation)

> 日期：2026-05-18
> 状态：**已确认核心概念**

---

## 1. 核心设计定稿
- **机制**：线索不是静态卡牌。在石碑辐射下，**未被及时分享/处理的线索会随时间“失真”或“被同化”**。
- **对抗囤积**：逼迫玩家必须即时交流，将私密线索从“博弈筹码”转化为“烫手山芋”。
- **与欺诈联动**：魔术师可在线索变质前“偷天换日”，用伪造 UI 替换即将失真的线索，实现系统级误导。
- **叙事契合**：完美解释“集体噩梦”与“证词趋同”——只有及时的碰撞与讨论才能锚定真相，抵抗精神同化。
