# 对话思考：角色讨论定位与能力不对称

> 日期：2026-05-18  
> 主题：六角色在讨论阶段的独特价值与信息位置

---

## 1. 核心原则

**不需要通用戳谎机制**。每个序列在讨论中有独特能力，不对称本身就是趣味。玩家作为"扮演者"，合理运用角色能力是核心乐趣。

---

## 2. 六角色讨论定位

### 心理医生（观众途径）
- **看穿人心**：洞察大成功额外获得隐情提示
- 讨论中的信息验证者，但她读不到魔术师（完美控制表情）
- 她的"读心"结果需要被二次信任——她说的不一定真

### 梦魇（黑夜途径）
- 高灵性 → 被动感知能力强，容易察觉被窥探
- 旧案经验 → 讨论中可引用相似案件建立可信度
- 与通灵者的隐性恋人关系 → 下意识偏袒

### 通灵者（收尸人途径）
- 从死者角度获取信息 → 情报来源与所有人不同
- 污染诊断 → 能判断尸体异常是否来自仪式/封印物
- 讨论中的"专业证人"

### 魔术师（占卜家途径）★ 黑箱
- 能完美控制表情和肢体语言 → **心理医生读不到他**
- 能制造幻觉（色彩/声音/气味，近乎真实）→ 伪造证据
- 占星/卡牌占卜/灵摆 → 独立的信息获取方式
- 纸人替身 → 首次大失败的后果可转移为假痕迹
- **讨论定位**：桌上唯一真正的"黑箱"，他是信息不对称的最高点

### 巫师（窥秘人途径）★ 不安制造者
- **窥秘之眼**：被动看到他人星灵体/以太体/心智体异常，**无法关闭**
- 看到的是**方向性**的：「此人有秘密」「灵体有异常」——而非具体内容
- 快速仪式 + 法术全面 → 知识面最广但伴随危险
- **讨论定位**：知道太多但不能全说（暴露自己的异常视角），是讨论中的"不安制造者"而非"答案提供者"

### 航海家（水手途径）★ 执行者
- 原著能力：磁场/洋流/风向直觉、水下活动、有限水法术
- 计算力、记忆力、距离判断力得到强化
- **讨论中较弱**，需在剧情中设计专属场合（如水域场景、追踪、封锁）
- **讨论定位**：不擅长讨论，但执行阶段无可替代。他说"我能封锁这个区域"就是真的能做到——**他的话有"执行力"的权威**

---

## 3. 信息位置光谱

```
完全透明 ←————————————————————————→ 完全黑箱
  通灵者     心理医生   梦魇   航海家    巫师    魔术师
  (证据说话) (能读人)  (被动感知) (执行权威) (知道太多) (完美欺骗)
```

- 魔术师是最右端：控表情、造幻觉、不被人读
- 巫师偏右：被动知道太多，但"说"和"不说"都是信息
- 心理医生偏左：专业验证者，但被魔术师克制

---

## 4. 关键克制关系

| A 对 B | 效果 |
|--------|------|
| 魔术师 → 心理医生 | 完美控制表情，心理医生读不到 |
| 巫师 → 所有人 | 被动方向性感知（"有秘密""灵体异常"），无法关闭 |
| 梦魇 → 窥探者 | 高灵性 → 大概率感知到被窥探 |
| 心理医生 → 梦魇 | 能读到他污染度，但梦魇可能反向感知 |
