# UI/UX 设计原则决议录（最终版）

> **说明**：本文件定义了游戏界面的核心交互原则与掷骰逻辑。

---

## 1. 谎言的最高级：系统级伪造
- **机制**：拥有“诡诈”能力的角色（如魔术师），有权生成**伪造的 UI 卡片/线索**。
- **表现**：其他玩家收到这张卡时，UI 显示的是伪造内容，且无法通过常规手段直接识破。

## 2. 污染/掉 SAN 的视觉表现
- **方案**：**背景/氛围异化**。
- **表现**：随污染度上升，游戏背景变暗、出现噪点或 UI 边缘产生“灵性侵蚀”感，不影响核心阅读。

## 3. 掷骰交互与底层逻辑（核心）
- **冲突解决**：**难度突破模式**（BG3 式）。
  - 先手方（如谎言/干扰）掷骰，设定**DC（难度等级）**。
  - 后手方（如洞察/反制）尝试掷骰突破该 DC。
  - **反馈限制**：后手方成功后**不知晓对方数值**，仅获“成功/失败/轻微感知”的定性提示。
- **主动检定**：明过程（动画可见）、暗结果（仅己方可见）、广播行为。
- **掀桌子机制**：**轻量级**。随手一点即可公开结果，不打断节奏。
- **底层原则**：万物皆可掷骰，不写死克制。
- **记忆支持**：系统提供**“私密投骰日志”**，自动记录历史。
