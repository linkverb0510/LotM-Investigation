# 对话思考：隐蔽交互链与被动感知系统

> 日期：2026-05-18  
> 主题：讨论阶段博弈机制、资源可见性、被动感知

---

## 1. 讨论机制核心设计（确认方向）

### 已确认的三个方向：

| 方向 | 要点 |
|------|------|
| **讨论有时间窗口** | 不是僵硬安排，而是由外部压力事件触发（如"石碑脉动"），在特定时间段/地点玩家可进行讨论 |
| **讨论中可烧灵性做额外行动** | 引入 D20 检定机制，体现不同序列能力差异。灵性有限，"现在用还是留"构成博弈 |
| **收束 = 凑资源** | 案件收束不是选 A 或 B，而是团队凑够灵性/知识/组织许可等资源总量。存在"个人任务 vs 团队目标"的博弈 |

---

## 2. 资源可见性分层

**核心原则**：灵性、污染度等数值不是 UI 面板公开数据，不能直接看到。

- 例如心理医生可消耗灵性 + 掷骰来感知他人状态
- 不同能力/角色的感知方式和结果不同
- 底层遵循D20和属性的机制

---

## 3. 隐蔽交互链设计

### 3.1 能力发动 → 私密（模式 A）

心理医生读梦魇 → 结果仅系统私信给她。她可以：
- 说实话
- 撒谎误导他人
- 完全不提

**能力本身变成「信息权 + 欺骗权」的双刃剑。**

### 3.2 被动感知 → 统一底层系统

**所有角色都有被动感知机会**，但基于：
- 个人属性值（灵性/洞察越高，掷骰加成越大）
- D20 掷骰结果（五档：天启/成功/勉强/失败/灾厄）

| 属性情况 | 典型角色 | 感知概率 |
|----------|---------|:------:|
| 灵性 6 | 梦魇、通灵者 | 高 |
| 灵性 5 | 魔术师、心理医生 | 中高 |
| 灵性 ≤3 | 代罚者军官 | 低（可能负加成） |
| 洞察 6 | 心理医生 | 高（对社交类窥探） |

### 3.3 感知结果分层（五档）

| 档位 | 获得的信息 |
|:----:|-----------|
| **天启** | 不仅知道被窥探，还能识别途径特征（如"观众途径的灵性波动"） |
| **成功** | 知道自己被窥探 |
| **勉强** | 模糊的不安感，不能确定 |
| **失败** | 无感知 |
| **灾厄** | 不仅不知道，还可能被植入虚假感知 |

### 3.4 不套娃原则

**当前阶段到 A 层为止**：发动者（心理医生）不知道目标是否察觉到自己。
- 梦魇知道自己被窥探 → 可以假装不知道，反向设局
- 心理医生不知道梦魇发现了 → 博弈信息不对称
- **不做发动者的"再感知"掷骰**，避免无限套娃

---

## 4. 设计要点总结

| 层级 | 说明 |
|------|------|
| 发动 | 私密，仅发动者知晓 |
| 目标感知 | 被动掷骰（属性+运气），分五档 |
| 发动者反馈 | 无——不自知暴露与否 |
| 桌面博弈 | 感知者知道被窥探但不知谁干的 → 讨论中的猜测、试探、反设局 |
