# 对话思考：开场设计与玩家第一体验

> 日期：2026-05-18  
> 主题：如何设计游戏开场的前 5 分钟

---

## 1. 开场设计三要素

### 1.1 独立到达动机（固定绑定）

每个角色有固定的出场理由，与剧情整体一致性挂钩：

| 角色 | 到达动机（待细化） |
|------|-------------------|
| 梦魇 | 教会正式派遣 / 值夜者职责 |
| 魔术师 | 塔罗会任务 / 情报收集 |
| 航海家 | 代罚者派遣 / 武力介入请求 |
| 心理医生 | 贵族委托 / 旧识联络 |
| 通灵者 | 教会派遣 / 尸体专业需求 |
| 巫师 | 知识教会派遣 / 仪式风险评估 |

动机固定绑定角色，不随机——这关乎剧情的整体正确性。

### 1.2 每个人有独特"第一眼"（B 模式）

到场时不是统一 briefing，而是每个角色基于自身能力感知到不同的东西。**通过掷骰来决定看到多少**：

- 梦魇 → 灵性检定，感知门口的灵体残影
- 巫师 → 知识检定，识别石碑周围的禁忌符纹
- 通灵者 → 灵性检定，感受死者残留情绪
- 魔术师 → 洞察/灵性检定，注意到占卜痕迹或异常痕迹
- 心理医生 → 洞察检定，捕捉现场环境给人的心理暗示
- 航海家 → 体质/洞察检定，感知空间格局的异常

**设计意图**：开场第一秒就在教玩家——「骰子很重要，你的属性决定了你能看到什么」。

### 1.3 系统引导破冰讨论

开场后不是散养，系统需要引导玩家开口。方式：
- 系统级提示：「你感觉自己注意到的异常值得向其他人说明，否则调查可能延误」
- 开局创造一个自然的"讨论"剧情 → 交换背景和身份
- 讨论过程中引导每个人认识自己的序列、能力特长

**核心洞察**：用游戏自身的机制来做教学——玩家第一次认识角色，不是读说明书，而是在桌上跟其他角色说话时自然发现的。

---

## 2. 开场流程概要（草案）

```
P0-1: 个人入场（每角色独立）
  → 系统展示到达动机文字
  → 掷骰感知"第一眼"
  → 获得仅自己可见的初始情报

P0-2: 聚集讨论（系统引导）
  → 系统提示引导玩家分享
  → 交换身份背景
  → 自然了解各自的序列与能力

P0-3: 触发事件（待设计）
  → 某种突发事件让讨论自然过渡到行动
  → 正式进入 P1 调查阶段
```

---

## 3. 待解决问题

- P0-3 的具体事件设计：什么事件能从"讨论"自然过渡到"调查行动"？
- 开场动机文本的篇幅控制：不能太长（影响节奏），但要有足够信息量
