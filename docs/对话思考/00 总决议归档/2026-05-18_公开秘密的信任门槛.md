# 对话思考：公开秘密的信任门槛

> 日期：2026-05-18  
> 主题：限制捷径、信任机制与防速通

---

## 1. 核心定稿：捷径需过“信任关”
**设计定稿**：玩家利用“秘密/隐情”作为捷径（如快速破案）时，不能随意触发，必须受到限制。

- **拒绝轻易破局**：防止玩家通过简单的“自爆卡车”式玩法跳过核心体验（黑暗中的摸索）。
- **限制形式倾向**：倾向于**“信任检定”**或类似机制。
  - 玩家提出“我知道这个秘密，让我来解”。
  - 触发全队信任投票 / 角色能力判定 / 资源抵押。
  - 通过后方可解锁捷径，失败则被视为误导或无效。

## 2. 衍生博弈：谎言与信任的筹码
- **信任的来源**：之前的合作表现、线索分享、角色关系包（如恋人）可能提供信任加成。
- **伪装**：坏人（如果有）或持有恶意隐情的人，可能利用此机制假装“为了团队牺牲”，实则骗取信任后搞破坏。
- **体验**：将“坦白”变成一种**高风险的社交博弈**。
