# 诡秘全设定研读与机制映射 (LOTM Lore Integration)

## 1. 核心领悟 (Key Takeaways)
- **失控与疯狂的代价**：力量体系 (序列) 的核心矛盾是“控制 vs 失控”。高序列意味着更强的能力，但也意味着更少的“人性”和更多的“神性/疯狂”。
- **锚 (Anchors)**：维持人性的关键。没有锚的高序列存在会迅速滑向失控。
- **扮演法 (Acting Method)**：消化魔药的方式。必须深刻理解并践行魔药名称的含义。

## 2. 对“筛选与献祭”的重新思考 (Refined Sacrifice Concept)
- **否定**：传统的“扣血换胜利”太廉价，不符合《诡秘》的基调。
- **修正**：在“运转的钟摆”面前，真正的筛选代价应该是**人性的丧失**或**不可逆的异化**。
- **新方向**：为了阻止石碑（本质是高序列污染的具象化），必须有人**主动承载污染**，甚至**部分失控**来作为“容器”或“封印物”。这不仅仅是数值上的牺牲，而是角色身份的根本转变（从调查员变成被封印的危险存在）。
