# 场景分层与深层机制（待深化设计）

## 1. 核心机制：地点分层 (Location Layering)
- **概念**：关键地点（如“旧教堂地下室”）不再是单一场景，而是分为多个层级。
- **层级构想**：
  - **表层**：物理环境（灰尘、脚印、普通物品）。
  - **里层**：隐藏结构（暗格、魔法阵纹路、特殊痕迹）。
  - **深层/核心**：异常源头（石碑本体、精神同化中心）。
- **目的**：增加游戏时长，提供差异化体验，强制团队合作（单一角色难以通吃所有层级）。

## 2. 待解决问题（实现难点）

### 2.1 准入机制设计
- **问题**：玩家如何从表层进入里层/深层？
- **方向**：
  - **方案 A（硬门槛）**：特定职业独有权限（如只有航海家能破门，只有巫师能解密）。
    - *优点*：职业差异大，合作必须。
    - *缺点*：可能卡关（若缺人则无法推进）。
  - **方案 B（软代价）**：全职业可进，但非本专业需承受高额代价（如污染+3，或检定难度 +5）。
    - *优点*：自由度高，增加“敢死队”博弈。
    - *缺点*：可能导致“所有人都在硬扛”的单调体验。
- **待决定**：采用哪种方案？或混合使用？

### 2.2 引导与票决机制
- **问题**：如何通过“多数票决”合理地引导玩家去往关键地点，而不产生“不知道该去哪”的迷茫感？
- **方向**：需要设计一套“线索热度”或“直觉”系统，在投票 UI 上给予暗示。

### 2.3 移步换景的视觉/叙事表现
- **问题**：从一层转入下一层时，界面和叙事如何平滑过渡？
