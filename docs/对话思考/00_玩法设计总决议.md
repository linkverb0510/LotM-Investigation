## 1. 游戏核心循环（Game Loop）

### 1.1 时间轴：单轮游玩结构
每轮固定三个阶段，循环执行：
- **阶段 A（移步/行动）**：玩家选择目标区域（地点），打出行动卡，指定具体行动。
- **阶段 B（探索/检定）**：结算 D20 检定。
  - **成功**：获得区域专属线索。
  - **合作**：同区域双人可触发互补检定（合成新线索）。
  - **失败/灾厄**：承受污染、假线索或状态异常。
- **阶段 C（换景/讨论）**：全员汇聚。
  - 分享/交易/隐瞒线索（信息私有制）。
  - **多数票决**决定下一轮团队的“主攻区域”（移步换景）。

### 1.2 空间轴：区域解锁逻辑
地点非全图开放，随主线进度（Golden Path）解锁：
- **P0**：① 封锁线外围（强制）
- **P1**：② 旧教堂地下室（核心现场）
- **P2+**：③ 东区居民区（需讨论决议解锁） / ④ 档案室/文献点（需讨论决议解锁）
- **主线驱动**：特定线索组合 + 票决 → 解锁并强制转移至下一重点区域。

### 1.3 角色与环境匹配
- **提示机制**：系统会根据角色序列给出探索方向提示（如：推荐航海家去封锁区，推荐巫师去地下室）。
- **非强制**：角色可以去任何地点，但检定可能受环境修正影响。

## 2. 终局与复盘（保留此前决议）
- **迷雾模式**：个人档案私密，鼓励线下交换复盘。
- **动态结局**：无绝对评级，只有客观记录（公共卷 + 个人卷）。

---

## 3. 空间推进与硬门槛
- **地点分层**：关键地点分为表层/里层/核心层，逐层解锁。
- **硬性门槛**：进入下一层必须由**特定序列/属性**的角色执行专属行动检定。不可跨职业硬闯。
- **设计目的**：强制合作，凸显职业不可替代性，杜绝“单人速通”。

## 4. 交互与博弈（保留此前决议）
- **资源可见性**：不公开面板，需检定感知。
- **合作机制**：浅层/深层共鸣分级，允许微操。
- **Boss 引入**：非实体战斗，而是“剥洋葱式”认知深化（环境 → 场域 → 结构 → 污染链）。
