# 核心玩法设计决议录 (2026-05-18 更新)

> **说明**：本文件汇集经讨论后确定的核心机制与高层设计哲学。

---

## 1. 终局与复盘机制 (已确认)
- **动态演化结局**：取消 S/A/B/C 评分。
- **客观记录书**：生成《案件记录书》（公共卷 + 个人卷）。
- **迷雾模式**：局内仅可见个人卷。鼓励线下/语音复盘时交换阅读，制造“罗生门”反转。

## 2. 重玩性设计 (Replayability)
- **动态压力系统（思路一）**：引入“石碑共振”机制。每局开局随机抽取频率（如“恐惧共振”、“认知干扰”），改变环境规则与检定难度。
- **元进程系统（思路三）**：参考《杀戮尖塔 2》，引入“历史节点解锁”。通过达成特定结局/条件解锁“绝密档案”。
- **知识隔离原则（关键决策）**：**场外解锁的知识绝不回流影响局内数值。** 游戏保持硬核解谜逻辑，防止“背板”。

## 3. 角色与环境匹配 (已确认)
- **地点分层**：表层 / 里层 / 核心层。
- **硬性门槛**：进入下一层必须由**特定序列/属性**的角色解锁（不可跨职业硬闯）。
- **资源买路（护航机制）**：若钥匙位角色无法行动，允许团队分摊资源（如消耗灵性、提供净化）辅助其通过。

## 4. UI/UX 与底层逻辑 (已确认)
- **谎言载体**：允许“系统级伪造”（魔术师可生成伪造 UI 线索）。
- **氛围表现**：通过“背景异化”表达掉 SAN 状态。
- **掷骰逻辑**：
  - 主动检定：明过程（动画可见）、暗结果（仅己方可见）、广播行为。
  - 冲突解决：难度突破模式（BG3 式）。
  - 记忆支持：系统提供“私密投骰日志”。

## 5. 待发散议题
- 阵容残缺时的系统适应性（刚性 vs 柔性）。
- 行动结算节奏（同时结算 vs 轮流结算）。
